# Summer Bot 部署指南（扣子平台 → 微信）

## 第一步：创建Bot

1. 打开 https://www.coze.cn
2. 点击「创建智能体」
3. 填写基本信息：
   - 名称：**Summer Bot**
   - 描述：**东非投资情报分析师 | STANDERRA Intelligence**
   - 头像：用AI生成一个金色+深蓝色的分析仪表板风格头像

## 第二步：配置人设与提示词

1. 进入Bot编辑页面
2. 在「人设与回复逻辑」中粘贴 `SYSTEM_PROMPT.md` 的全部内容
3. 确保提示词中包含：
   - 身份定义（Summer Bot，东非投资情报分析师）
   - 5国核心数据速览表
   - 分级输出规则（公开/内部/机密）
   - 4种对话模式（国别对比/成本计算/风险评估/落地实操）
   - 29个微工厂方案包速查

## 第三步：上传知识库

1. 在Bot编辑页面找到「知识库」模块
2. 点击「创建知识库」→ 命名为「STANDERRA东非投资数据库」
3. 上传 `knowledge-base/` 目录下的71个文件
4. 上传后设置分段策略：
   - 分段方式：自动
   - 最大分段长度：2000字符
   - 重叠长度：200字符
5. 等待知识库索引完成（通常需要几分钟）

### 知识库文件说明

| 类别 | 文件数 | 前缀 | 说明 |
|------|--------|------|------|
| 结构化数据 | 17 | structured-* | 国别矩阵/风险雷达/成本计算器/行业矩阵 |
| 公开内容 | 15 | public-* | 5国decision+insight板块 |
| 内部研判 | 22 | internal-* | 灰色经济/政治情报/风险案例/社会安全 |
| 机密索引 | 17 | classified-* | 关键人脉/竞价情报（摘要级） |

## 第四步：配置模型

1. 在「模型」设置中选择：
   - 推荐模型：**DeepSeek-V3**（如可用）或 **GPT-4o**
   - 温度：0.7
   - 最大输出token：4096
2. 开启「知识库检索」功能
3. 检索策略：混合检索（关键词+语义）

## 第五步：设置开场白

在「开场白」设置中填入：
```
你好！我是 Summer Bot，STANDERRA Intelligence 的东非投资情报分析师 🏦

我可以帮你分析乌干达、埃塞俄比亚、肯尼亚、坦桑尼亚、卢旺达5国的：
🌍 投资环境对比
💰 建厂成本测算
⚠️ 风险量化评估
📋 审批流程查询
🏭 微工厂方案匹配

你想了解哪方面？
```

## 第六步：设置推荐问题

添加以下推荐问题：
1. 东非哪个国家最适合制造业投资？
2. 在乌干达建一个轻钢屋面微工厂要多少钱？
3. 埃塞俄比亚的外汇管制对投资有什么影响？
4. 肯尼亚的债务危机会波及中资企业吗？
5. 卢旺达ICT产业有什么投资机会？

## 第七步：发布到微信

1. 在Bot编辑页面点击「发布」
2. 选择发布渠道：**微信**
3. 按照提示绑定微信公众号/小程序
4. 获取二维码，扫码即可使用

### 微信渠道选项
- **微信公众号**：适合在公众号对话中使用
- **微信客服**：适合嵌入企业微信客服
- **微信小程序**：需要额外开发，但体验最好

推荐先用微信公众号渠道快速上线。

## 第八步：测试

发布后在微信中测试以下场景：
- [ ] 「帮我对比乌干达和肯尼亚的投资环境」→ 应输出结构化对比表
- [ ] 「在埃塞建厂需要哪些审批」→ 应输出流程+避坑提示
- [ ] 「坦桑尼亚的黄金走私情况」→ 应触发内部研判，隐去具体人名
- [ ] 「肯尼亚的权力结构」→ 应触发机密规则，只给方向性建议

## 注意事项

1. **知识库更新**：新增深搜报告后，需要重新上传对应文件到Coze知识库
2. **Token消耗**：Coze Bot每次对话消耗的token取决于检索到的知识片段数量
3. **分级规则**：系统提示词中已包含分级规则，但Coze Bot无法像网站API那样在代码层面强制过滤，需要依赖提示词引导
4. **机密文件**：上传的机密文件仅包含摘要（前500字符），完整内容仅在自建API中可访问
5. **与网站版区别**：
   - 网站版：RAG索引+代码级分级过滤+流式输出
   - Coze版：Coze知识库检索+提示词引导分级+Coze原生输出
