# 🌾 卢旺达农业转型

> 从自给农业到出口导向

---

## 农业结构变化

| 时期 | 特征 |
|------|------|
| 传统农业 | 自给为主，粮食作物 |
| 转型期 | 经济作物引入 |
| 现在 | 咖啡/茶叶出口导向 |
| 未来 | 精品化+品牌化 |

---

## 主要变化

| 变化 | 内容 |
|------|------|
| 产业结构 | 农业GDP占比30%→20% |
| 出口结构 | 初级品→认证精品 |
| 价值链 | 原矿→加工→品牌 |

---

**农业转型结论**：卢旺达农业正在从自给农业向精品出口转型，咖啡和茶叶是核心驱动力。
