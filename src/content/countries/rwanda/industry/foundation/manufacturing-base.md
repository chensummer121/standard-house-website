### 行业结构

```
卢旺达制造业结构（按增加值）
├── 食品饮料 (45%) — Bralirwa啤酒、Bralima饮料
├── 建筑材料 (20%) — 水泥、钢材加工
├── 纺织服装 (10%) — CMT出口加工
├── 化学品 (10%) — 肥皂、清洁剂
├── 其他 (15%) — 纸张、印刷、家具
└── 高技术制造 (<5%) — 极度缺乏
```

## 七、关键成功因素

### ✅ 必须具备

| 因素 | 说明 |
|------|------|
| KSEZ/KIZ入驻 | 锁定基础设施和激励 |
| 本地化比例 | 70%+员工为本地人 |
| 电力保障 | 自备UPS/发电机 |
| 供应链本地化 | 降低进口依赖 |
| 合规运营 | RRA税务、RSSB社保 |

### ⚠️ 常见陷阱

| 陷阱 | 描述 | 规避 |
|------|------|------|
| 电力依赖 | 停电导致生产中断 | 自备电源 |
| 物流成本 | 内陆国出口成本高 | EAC市场优先 |
| 市场规模 | 1400万人口体量限制 | EAC布局 |
| 汇率风险 | RWF贬值 | 本币留存最小化 |
| 人才短缺 | 技术工人不足 | 提前培训 |

---

**产业结论**：卢旺达制造业是"劳动力洼地+EAC关税保护+政策激励"三重优势，但必须接受"电力约束+物流成本+市场体量"三重挑战。最佳策略是聚焦"低电力依赖+高关税保护+本地原料"的赛道——农产品加工、CMT纺织、建材。
