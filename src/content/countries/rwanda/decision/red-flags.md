# 🚫 卢旺达投资红线清单

> 识别高风险信号，避免投资陷阱

---

## 一、法律合规红线

### 🔴 绝对禁止

#### 外资禁入行业
| 行业 | 限制内容 | 违规后果 |
|------|----------|----------|
| 军事/国防 | 武器制造、军事服务 | 刑事处罚+资产没收 |
| 毒品相关 | 麻醉品生产/贸易 | 极刑风险 |
| 博彩（部分） | 陆地赌场 | 许可证吊销 |

#### 合规底线
- **反腐败**：禁止任何形式的商业贿赂（卡加梅政府零容忍）
- **环境**：禁止未批先建，需RDB环评认证
- **劳动**：强制本地员工占比（最低70%）；最低工资$87/月
- **土地**：外国人不得拥有土地所有权，仅可租赁（99年租约）

## 二、商业风险红线

### 🟠 高风险信号

#### 合作伙伴尽职调查
| 红牌信号 | 风险等级 | 应对措施 |
|----------|----------|----------|
| 无RDB认证 | 高 | 要求出示投资许可证 |
| 要求现金付款 | 极高 | 立即终止 |
| 承诺"特殊渠道" | 高 | 可能是腐败或欺诈 |
| 无实体办公地址 | 高 | 实地核查 |
| 股东背景模糊 | 中 | 反洗钱调查 |

#### 合同风险条款
| 红牌信号 | 风险描述 |
|----------|----------|
| 仲裁地在卢旺达 | 法律环境偏向本地企业 |
| 无价格调整条款 | 通货膨胀/汇率风险 |
| 无限连带责任 | 风险敞口无限 |
| 禁止转让条款 | 退出机制受限 |

## 三、金融红线

### 🟠 外汇与支付

| 红牌信号 | 风险描述 |
|----------|----------|
| 要求用RWF结算 | 汇率风险累积 |
| 大额现金交易要求 | 反洗钱风险 |
| 延迟付款超过90天 | 信用风险 |
| 无银行流水记录 | 资金来源可疑 |

### 🔴 货币风险管理
- **RWF历史年均贬值2-4%**
- **建议**：卢旺达业务RWF留存不超过3个月运营成本
- **汇率锁定**：与Equity Bank/ Bank of Kigali签订远期合约

## 五、行业特定红线

### 🔴 矿业
- **未批先采**：无RDB/MMG许可的采矿活动属刑事犯罪
- **环境违规**：刚果边境地区环境监管趋严
- **社区冲突**：土地补偿纠纷可能导致项目停滞

### 🔴 农业
- **土地侵占**：租用土地需村长-区长-中央三级审批
- **出口配额**：部分农产品出口需NAEB配额许可
- **农药残留**：欧盟市场严查，需GlobalGAP认证

### 🔴 ICT
- **数据本地化**：金融/医疗数据需本地存储
- **网络安全法**：2024年网络安全法对数据跨境有限制
- **许可证**：部分ICT服务需RISA（卢旺达ICT管理局）许可

|------|------|

| EAC区域安全恶化 | 暂停新投资 |
| 外汇管制升级 | 加速利润汇出 |
| 政策逆转 | 启动退出条款 |

## 七、尽职调查清单

### 入场前必查

- [ ] RDB投资许可证（Certificate of Registration）
- [ ] RRA税务登记（Tax Identification Number）
- [ ] RSSB社保登记
- [ ] 土地租赁协议（经公证）
- [ ] 环评批复（如果需要）
- [ ] 行业特定许可证（如矿业许可、医疗执照等）
- [ ] 合作伙伴背景调查（反洗钱筛查）
- [ ] 银行账户开立（确认外资企业开户政策）

### 运营中持续监控

- [ ] 季度RRA税务合规检查
- [ ] 年度RSSB社保缴纳核查
- [ ] 劳动法合规审计
- [ ] 环境合规检查
- [ ] 外汇风险敞口评估

---

**红线总结**：卢旺达整体营商环境是非洲最佳之一，但"非洲最廉洁"不等于"零风险"。投资前务必完成RDB一站式注册锁定合规身份，避免触碰政治红线，保持灵活退出机制。
