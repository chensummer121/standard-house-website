## 四象限分析

### 🔥 高影响力 + 高紧迫性（现在进入）

#### ICT/BPO服务外包
- **政策红利**：ITIDA认证企业免征10年企业所得税；RDB一站式服务
- **市场机会**：欧洲企业外包需求爆发；卢旺达时区(UTC+2)+英语优势
- **门槛要求**：$10万+注册资本；本地员工占比70%+

#### 数字支付/Fintech
- **政策红利**：BNR数字支付牌照加速审批；Sandbox监管沙盒
- **市场机会**：72%数字支付普及率，仍有巨大空白；移动支付渗透率提升空间大
- **门槛要求**：$50万+注册资本；本地合作伙伴

---

### 📈 高影响力 + 低紧迫性（战略布局）

#### 可再生能源
- **政策红利**：NST2承诺2030年清洁能源占比60%；PPA上网电价保护
- **市场机会**：缺电=长期机会；太阳能已具备经济性
- **门槛要求**：$100万+项目投资；与REG(Rwanda Energy Group)签署PPA

#### 精品咖啡
- **政策红利**：NAEB咖啡升级计划；精品认证体系完善
- **市场机会**：全球精品咖啡需求年增15%；卢旺达精品豆溢价30%+
- **门槛要求**：$50万+产能投资；合作社绑定

---

### ⏰ 低影响力 + 高紧迫性（短期机会）

#### 农产品加工
- **机会**：本地供需缺口；进口替代政策
- **风险**：原材料供应不稳定；电力成本高
- **建议**：小规模试水，聚焦乳制品/蜂蜜/谷物

---

### ⏳ 低影响力 + 低紧迫性（观察）

#### 制造业/大众零售
- **原因**：市场体量限制；电力/物流瓶颈
- **建议**：除非有区域整合战略，否则暂缓

## 推荐组合策略

### 策略A：数字经济主导型（适合科技/服务企业）
```
1. 在Kigali注册区域总部 → 享受EAC市场准入
2. 申请ITIDA认证 → 10年免税
3. 与基加利大学合作 → 人才pipeline
4. 拓展肯尼亚/坦桑尼亚市场
```

### 策略B：精品农业主导型（适合贸易/消费品企业）
```
1. 绑定咖啡/茶叶合作社
2. 投资湿处理厂/精加工线
3. 申请精品认证(UTZ/Rainforest/Gorilla)
4. 布局欧洲/美国精品渠道
```

### 策略C：资源套利型（适合矿业/能源企业）
```
1. RDB矿业一站式服务
2. 3T矿产勘探/开采许可
3. 精炼厂投资→出口增值
4. AfCFTA框架下出口非洲市场
```
