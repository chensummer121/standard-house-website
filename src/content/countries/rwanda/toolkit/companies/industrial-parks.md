# 🏭 卢旺达工业园区

> 制造业和科技企业的首选载体

---

## KSEZ (Kigali Special Economic Zone)

### 基本信息

| 项目 | 数据 |
|------|------|
| 位置 | Kigali东部，Nyagatare Road |
| 面积 | 1,500公顷 |
| 成立 | 2009年 |
| 入驻企业 | 80+家 |
| 运营机构 | KSEZ Authority |

### 入驻企业行业

| 行业 | 代表企业 |
|------|----------|
| 矿业加工 | 天宇矿业等 |
| 制造业 | CIMERWA等 |
| 物流 | 仓储企业 |
| 农产品加工 | 食品加工 |

### 优惠条件

| 项目 | 内容 |
|------|------|
| 土地租金 | $3-8/m²/年 |
| 所得税 | 前5年0%，后5年15% |
| 增值税 | 进口设备/原材料免税 |
| 关税 | 进口设备/原材料免税 |
| 服务 | 一站式基础设施 |

| 项目 | 数据 |
|------|------|
| 位置 | Kigali西部，Kimironko |
| 面积 | 61公顷 |
| 成立 | 2019年(规划) |
| 定位 | 非洲科技创新中心 |

| 产业 | 说明 |
|------|------|
| ICT/软件 | 软件开发、BPO |

| 金融科技 | 支付、信贷 |
| 科技研发 | R&D中心 |
| 教育科技 | EdTech |

### 优惠条件

| 项目 | 内容 |
|------|------|
| 土地租金 | $8-15/m²/年 |
| 所得税 | ITIDA 10年免税 |
| 增值税 | 出口服务免税 |
| 配套 | 商业、住宅、学校 |

## 入驻流程

```
Step 1: RDB接洽
  → 了解园区土地情况

Step 2: 提交申请
  → 商业计划书
  → 投资规模
  → 用地需求

Step 3: 园区审批
  → KSEZ/KIZ管理局审核

Step 4: 签约
  → 签署租赁协议
  → 支付押金+首年租金

Step 5: 建设运营
  → 获得施工许可
  → 投产
```

## 园区对比

| 园区 | 租金 | 适合产业 | 基础设施 |
|------|------|----------|----------|
| KSEZ | $3-8/m²/年 | 制造、矿业 | 完善 |
| KIZ | $8-15/m²/年 | ICT、科技 | 完善 |
| Bugesera | $2-5/m²/年 | 制造 | 开发中 |
| Rwamagana | $2-5/m²/年 | 农业加工 | 一般 |

---

**园区结论**：KSEZ和KIZ是卢旺达最成熟的工业园区，前者适合制造业，后者适合ICT企业。入驻可享受5-10年所得税免税和基础设施配套。
