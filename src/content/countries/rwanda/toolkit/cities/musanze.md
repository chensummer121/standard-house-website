# 🏔️ 穆桑泽 (Musanze) 城市档案

> 火山旅游门户，矿业重镇

---

## 基本信息

| 项目 | 数据 |
|------|------|
| 人口 | 40万+ |
| 位置 | 北部省 |
| 海拔 | 2,000 m |
| 气候 | 高山凉爽 |
| 别称 | 火山门户 |

---

## 经济特征

| 项目 | 数据 |
|------|------|
| 主导产业 | 矿业、旅游、农业 |
| 锡/钨产量 | 全国40% |
| 火山游客 | 年10万+ |
| 城镇化 | 25%+ |

---

## 投资机会

### 优势

| 优势 | 说明 |
|------|------|
| 矿业资源 | 3T矿产丰富 |
| 火山旅游 | 临近维龙加火山公园 |
| 土地成本 | 远低于基加利 |
| 劳动力 | 矿工/农民充足 |

### 挑战

| 挑战 | 说明 |
|------|------|
| 基础设施 | 山区道路困难 |
| 电力 | 供电不稳定 |
| 教育资源 | 有限 |
| 医疗资源 | 有限 |

---

## 矿业资源

| 矿种 | 产量占比 | 说明 |
|------|----------|------|
| 锡 | 40%+ | 主要产区 |
| 钨 | 30%+ | 重要产区 |
| 钽 | 20% | 潜力大 |

---

## 投资建议

| 适合领域 | 说明 |
|----------|------|
| 矿业加工 | 产地优势 |
| 矿业服务 | 设备/物流 |
| 火山旅游 | 旅游配套 |
| 农业加工 | 马铃薯/芸豆 |

---

**城市结论**：穆桑泽是矿业和火山旅游的双重门户，适合矿业投资和旅游配套开发，但需接受山区基础设施的挑战。
