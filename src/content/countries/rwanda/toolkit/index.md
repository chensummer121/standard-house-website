## 投资决策路线图

```
Step 1: 市场调研 (1-2月)
  → 行业选择 → 竞争分析 → 政策研究

Step 2: RDB接洽 (2-4周)
  → RDB投资注册 → ITIDA认证(如适用) → 激励锁定

Step 3: 公司设立 (1-2周)
  → 公司注册 → 银行开户 → 税务登记

Step 4: 运营准备 (1-3月)
  → 场地租赁 → 人员招聘 → 设备采购

Step 5: 正式运营
  → 生产/服务启动 → 合规运营 → 持续扩展
```
