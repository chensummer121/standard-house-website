# 🏢 卢旺达公司法

> 公司类型、注册流程、治理结构

---

## 公司类型

### 常见公司类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 私人有限公司(Ltd) | 最常见，最灵活 | 绝大多数外资企业 |
| 公共有限公司(Plc) | 可上市，门槛高 | 大型股份公司 |
| 分公司 | 外国公司延伸 | 谨慎使用 |
| 代表处 | 市场调研用 | 不得从事商业活动 |
| 合伙企业 | 无限连带责任 | 极少使用 |

### 私人有限公司 (Ltd)

| 要求 | 标准 |
|------|------|
| 最低股东 | 1人 |
| 最高股东 | 50人 |
| 最低注册资本 | RWF 10万(约$80) |
| 董事要求 | 最少1人 |
| 审计要求 | 年营业额>5亿需审计 |

---

## 公司注册流程

### RDB一站式注册

| 步骤 | 时效 | 说明 |
|------|------|------|
| 1. 名称核准 | 1-2小时 | RDB系统 |
| 2. 提交材料 | 即时 | 线上提交 |
| 3. 审核批准 | 4-24小时 | RDB一站式 |
| 4. 获得证书 | 即时 | 公司注册证书 |
| 5. 税务登记 | 1-2天 | RRA自动 |
| 6. 社保登记 | 1周 | RSSB |

### 注册材料

| 材料 | 说明 |
|------|------|
| 公司名称 | 3个备选名称 |
| 股东信息 | 护照+地址证明 |
| 董事信息 | 护照+无犯罪记录 |
| 注册资本 | 金额和货币 |
| 注册地址 | 基加利地址 |
| 经营范围 | 具体业务描述 |
| 公司章程 | 标准模板可用 |

### 注册费用

| 项目 | 费用 | 说明 |
|------|------|------|
| 基础注册 | $100 | 注册资本<RWF500万 |
| 中级注册 | $250 | 注册资本500万-1亿 |
| 高级注册 | $500 | 注册资本>1亿 |
| 加急服务 | +$100 | 1小时出证 |

## 公司治理

### 董事会要求

| 要求 | 标准 |
|------|------|
| 董事人数 | 最少1人 |
| 董事资格 | 年满18岁，无犯罪记录 |
| 董事国籍 | 无限制，外国人可100% |
| 董事会权限 | 公司最高决策机构 |
| 会议频率 | 年至少1次 |

### 股东权利

| 权利 | 说明 |
|------|------|
| 投票权 | 按股权比例 |
| 分红权 | 按股权比例 |
| 信息权 | 查阅账目 |
| 转让权 | 受章程限制 |
| 优先购买权 | 转让时 |

---

## 财务与合规

### 财务报告要求

| 要求 | 标准 |
|------|------|
| 财年 | 12月31日或自定义 |
| 审计要求 | 年营业额>5亿需审计 |
| 年度申报 | 每年3月31日前 |
| 银行账户 | 需在卢旺达银行开立 |

### 税务登记

| 税种 | 说明 |
|------|------|
| TIN(税务号) | 自动分配 |
| VAT注册 | 年营业额>2,000万需注册 |
| 员工税 | 代扣代缴 |
| 预提税 | 股息/利息/特许权 |

---

## 实际操作要点

### 注册后事项

| 事项 | 时效 | 说明 |
|------|------|------|
| 开设银行账户 | 1-2周 | 需公司注册证书 |
| 申请工作许可 | 2-4周 | 外国员工 |
| 申请营业执照 | 1周 | 部分行业 |
| 租赁办公室 | 1-4周 | 商业租赁 |
| 社保注册 | 1周 | RSSB |

### 注意事项

- **名称核准**：提前查询避免重复
- **注册资本**：建议50万RWF以上
- **注册地址**：必须真实有效
- **银行开户**：NDL/BOK/Equity等可开
- **年度合规**：年报+审计不可忽视

---

## 外资特殊要求

| 要求 | 内容 |
|------|------|
| 外国董事 | 需工作许可 |
| 资本汇入 | 需银行备案 |
| 利润汇出 | 需RRA完税证明 |
| 外资认证 | RDB投资注册 |

---

**公司法结论**：卢旺达公司注册是非洲最便捷的，RDB一站式24小时完成。建议注册Ltd类型，注册资本50万RWF起，银行开户和税务合规是运营关键。
