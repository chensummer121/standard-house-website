# ⛏️ 卢旺达矿业法典

---

| 法规 | 说明 |
|------|------|
| Mining and Quarry Law 2018 | 矿业基本法 |

| 机构 | 职能 |

## 矿业许可类型

### 许可分类

| 许可类型 | 面积 | 期限 | 费用 | 可续 |
|------|------|------|------|------|
| 勘探许可证 | 500-5,000公顷 | 3年 | $5-50/公顷 | 可续2年 |
| 采矿许可证 | 按需 | 25年 | 环评+社区 | 可续15年 |
| 特别采矿证 | 大型 | 30年 | 议会批准 | 可续20年 |
| 加工许可证 | - | 10年 | $5,000 | 可续 |

### 勘探许可证

| 项目 | 说明 |
|------|------|
| 申请条件 | 资金能力+技术能力 |
| 最低资本 | $50,000 |
| 最低投资 | 第一年$20,000 |
| 环境影响 | 需初步环评 |
| 社区通知 | 需公告 |

### 采矿许可证

| 项目 | 说明 |
|------|------|
| 申请条件 | 勘探完成+可行性研究 |
| 技术能力 | 需采矿设备+人员 |
| 环境影响 | 需完整环评 |
| 社区补偿 | 需土地补偿协议 |
| 本地参与 | 需5%本地股权 |

## 矿业税费

### 主要税费

| 税种 | 税率 | 说明 |
|------|------|------|
| 所得税 | 25% | 可申请减免 |
| 特许权费 | 3-5% | 从价征收 |
| 增值税 | 18% | 可抵扣 |
| 出口税 | 0% | 矿产免征 |
| 预提税 | 15% | 非居民股息 |

### 特许权费详细

| 矿种 | 税率 | 计价基础 |
|------|------|----------|
| 锡 | 3% | FOB价格 |
| 钨 | 3% | FOB价格 |
| 钽 | 3% | FOB价格 |
| 金 | 5% | FOB价格 |
| 其他矿产 | 3-5% | 视矿种 |

## 3T矿产规定

### 锡(Tin)

| 项目 | 说明 |
|------|------|
| 主要产区 | 北部省、西部省 |
| 开采方式 | 露天+地下 |
| 选矿 | 重力选矿为主 |
| 出口要求 | 精矿含锡>60% |
| 负责任矿产 | 需RMI认证 |

### 钨(Tungsten)

| 项目 | 说明 |
|------|------|
| 主要产区 | 东部省、北部省 |
| 矿物形式 | 白钨矿、黑钨矿 |
| 选矿 | 重选+浮选 |
| 出口要求 | 精矿含钨>60% |
| 全球需求 | 硬质合金主要原料 |

### 钽(Tantalum)

| 项目 | 说明 |
|------|------|
| 主要产区 | 西部省、南部省 |
| 矿物形式 | 铌铁矿、钽铁矿 |
| 选矿 | 电磁选+重选 |
| 出口要求 | 精矿含钽>30% |
| 应用 | 电子元件主要原料 |

## 本地化要求

### 本地股权

| 要求 | 说明 |
|------|------|
| 采矿许可证 | 需5%本地股权 |
| 加工设施 | 需10%本地股权 |
| 社区利益 | 需2%利润社区发展 |

### 就业本地化

| 要求 | 比例 |
|------|------|
| 管理人员 | 30%本地 |
| 技术人员 | 50%本地 |
| 普通工人 | 80%本地 |
| 培训计划 | 必须提交 |

## 环境要求

### 环评程序

```
Step 1: 初步环境评估
  → 筛选项目类别

Step 2: 编制EIA
  → 环境影响报告

Step 3: 公众咨询
  → 社区参与

Step 4: REMA审批
  → 环境许可证

Step 5: 监测计划
  → 定期报告
```

### 环境保证金

| 项目类型 | 保证金 | 说明 |
|----------|--------|------|
| 小型采矿 | $10,000 | 小规模 |
| 中型采矿 | $50,000 | 中等规模 |
| 大型采矿 | $200,000 | 大型项目 |

## 操作实务

### 申请流程

```
Step 1: RDB接洽
  → 了解矿业投资政策

Step 2: 编制申请材料
  → 公司文件
  → 技术方案
  → 融资计划
  → 环评初步

Step 3: MEME审批
  → 技术审查
  → 社区公告
  → 部长批准

Step 4: 获得许可
  → 缴纳费用
  → 签署协议
  → 开始运营
```

### 申请材料清单

| 材料 | 说明 |
|------|------|
| 公司注册文件 | RDB注册证书 |
| 技术方案 | 开采方法+设备 |
| 财务方案 | 投资+回报计划 |
| 环评初步 | 环境初步评估 |
| 社区方案 | 补偿+发展计划 |
| 技术资质 | 采矿能力证明 |
| 资金证明 | 银行存款证明 |

---

**矿业法结论**：卢旺达矿业法律框架完善，3T矿产(锡/钨/钽)是核心。勘探许可3年可续，采矿许可25年，需5%本地股权和环评。RDB一站式+MEME审批是主要流程。
