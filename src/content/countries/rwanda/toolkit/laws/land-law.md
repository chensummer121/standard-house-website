# 🏞️ 卢旺达土地法

> 土地权属、租赁规定、外国人投资

---

## 土地制度基础

### 土地权属类型

| 类型 | 权利 | 说明 |
|------|------|------|
| 国家土地 | 国家所有 | 公共用途 |
| 公有土地 | 政府机构 | 授权使用 |
| 私人土地 | 个人/法人 | 登记确认 |
| 习惯地 | 社区所有 | 传统持有 |

### 宪法规定

> 卢旺达宪法第34条：土地属国家财产，不得买卖外国人。

| 规定 | 说明 |
|------|------|
| 外国人所有权 | ❌ 禁止 |
| 外国人租赁权 | ✅ 允许，最长99年 |
| 建筑物所有权 | ✅ 租赁土地上可持有 |

---

## 外国人投资土地

### 租赁模式

| 项目 | 说明 |
|------|------|
| 租赁期限 | 最长99年，可续约 |
| 租赁协议 | 需公证 |
| 用途限制 | 按批准用途使用 |
| 续约权 | 可申请续约99年 |

### 租赁流程

```
Step 1: 选址确定
  → 确定土地位置和用途

Step 2: 土地核查
  → 确认土地权属(无纠纷)
  → 在土地登记处查询

Step 3: 申请审批
  → 区级政府同意
  → 部长级批准(大面积)

Step 4: 签署协议
  → 签订租赁协议
  → 公证处公证

Step 5: 登记
  → 土地登记处登记
  → 获得土地使用权证
```

## 风险与注意事项

### 主要风险

| 风险 | 描述 | 规避 |
|------|------|------|
| 土地纠纷 | 历史遗留纠纷多 | 彻底尽职调查 |
| 审批延迟 | 审批周期长 | 提前申请 |

**土地法结论**：外国人无法拥有土地，但可获得99年租赁权。建议通过KSEZ/KIZ获得工业用地（租金优惠+基础设施完善），或与本地合伙人合资持有土地权益。土地尽职调查是关键。
