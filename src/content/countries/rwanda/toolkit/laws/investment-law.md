# 📜 卢旺达投资法

> 投资准入、外资权益、激励政策

---

## 外资准入框架

### 外资可持股行业

| 行业 | 外资持股 | 说明 |
|------|----------|------|
| 制造业 | 100% | 大部分行业 |
| 服务业 | 100% | 金融、ICT等 |
| 贸易/零售 | 100% | 已对外资开放 |
| 建筑业 | 100% | 无限制 |
| 农业 | 100% | 土地租赁99年 |
| 采矿业 | 100% | 需许可 |

### 外资受限行业

| 行业 | 限制 | 说明 |
|------|------|------|
| 武器制造 | 禁止 | 国家安全 |
| 毒品生产 | 禁止 | 刑事责任 |
| 博彩(部分) | 需特别许可 | 严格监管 |
| 军事服务 | 禁止 | 国家安全 |

---

## 投资机构

### RDB (Rwanda Development Board)

| 服务 | 内容 | 时效 |
|------|------|------|
| 公司注册 | 一站式注册 | 24小时 |
| 投资认证 | 激励资格认定 | 1-2周 |
| 环境评估 | 环评审批 | 2-4周 |
| 土地许可 | 租赁协调 | 2-6月 |
| 行业许可 | 特殊行业 | 1-4周 |

### 投资注册流程

```
1. RDB接洽 → 投资咨询
2. 提交投资计划 → RDB审核
3. 获得投资注册证书 → 正式批准
4. 公司注册 → RBD一站式
5. 行业许可 → 相关部门
6. 税务登记 → RRA
7. 社保登记 → RSSB
8. 正式运营
```

## 投资激励政策

### 通用激励

| 激励类型 | 条件 | 内容 |
|----------|------|------|
| 投资补贴 | 固定资产>50万 | 一次性5%补贴 |
| 培训补贴 | 本地员工培训 | $200/人 |
| 研发抵扣 | 营收>5%投入研发 | 当年抵扣 |
| 出口补贴 | 出口额>50万 | 2-5% |

### 区域激励 (KSEZ/KIZ)

| 激励 | 内容 | 期限 |
|------|------|------|
| 所得税免税 | 0% | 前5年 |
| 所得税减半 | 15% | 后5年 |
| 增值税 | 0% | 进口设备/原材料 |
| 关税 | 0% | 原材料进口 |

### 行业激励

| 行业 | 激励 | 条件 |
|------|------|------|
| ICT/ITIDA | 10年免税 | ITIDA认证 |
| 影视制作 | 3年免税 | 文化部批准 |
| 能源(IPP) | PPA保障 | 购电协议 |
| 农业加工 | 5年免税 | 出口导向 |

## 实际操作

### 必备文件

| 文件 | 用途 |
|------|------|
| 商业计划书 | RDB审核 |
| 投资金额证明 | 资金来源 |
| 股东护照 | 身份核验 |
| 无犯罪记录 | 股东背景 |
| 场地意向书 | 运营地址 |

### 注意事项

- **RDB是核心**：所有投资相关事项先找RDB
- **投资认证先行**：先拿投资证书再注册公司
- **ITIDA认证**：ICT企业必做，可享10年免税
- **本地化要求**：大多数行业要求70%+本地员工

---

**投资法结论**：卢旺达投资法是非洲最开放的法律框架之一，外资可100%持股，无强制合资要求。充分利用RDB一站式和ITIDA/KSEZ激励是降低税负的关键。
