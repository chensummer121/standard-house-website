# 👷 卢旺达劳动法

> 雇佣关系、工资标准、劳动保护

---

## 劳动合同

### 合同类型

| 类型 | 期限 | 说明 |
|------|------|------|
| 固定期限合同 | 不超过1年 | 可续约 |
| 不定期合同 | 无固定期限 | 长期雇佣 |
| 试用期 | 最长6个月 | 工资80% |
| 学徒合同 | 培训期限 | 特殊规定 |

### 合同必备条款

| 条款 | 说明 |
|------|------|
| 雇主信息 | 公司名称、地址 |
| 雇员信息 | 姓名、职位 |
| 工作内容 | 职责描述 |
| 工作地点 | 地点说明 |
| 工资待遇 | 金额、支付周期 |
| 工作时间 | 工时制度 |
| 休假权利 | 年假等 |
| 合同期限 | 起止日期 |

### 最低工资（2024）

| 标准 | 金额 | 说明 |
|------|------|------|
| 一般最低工资 | RWF 100,000/月 (~$78) | 全职 |
| 技术工人 | RWF 150,000-300,000/月 | 视技能 |
| 管理人员 | 面议 | 无上限 |
| 加班工资 | 正常工资×1.5 | 超时 |

| 组成部分 | 说明 |
|----------|------|

| 住房补贴 | 雇主自定 |
| 交通补贴 | 雇主自定 |
| 绩效奖金 | 绩效挂钩 |
| 其他补贴 | 餐补等 |

## 解雇与补偿

### 合法解雇理由

| 理由 | 说明 |
|------|------|
| 经济性裁员 | 经营需要 |
| 绩效不达标 | 改进无效 |
| 违纪 | 严重违规 |
| 合同到期 | 固定期限 |
| 能力不足 | 调岗无效 |

### 解雇补偿

| 服务年限 | 补偿标准 |
|----------|----------|
| <6个月 | 无 |
| 6-12个月 | 15天工资 |
| 1-3年 | 1个月工资 |
| 3-5年 | 2个月工资 |
| >5年 | 3个月工资 |

### 违法解雇

- 无故解雇需支付2倍补偿
- 歧视性解雇可索赔
- 不当解雇可申请仲裁

## 合规要点

### 必须遵守

| 要求 | 说明 |
|------|------|
| 书面合同 | 入职30天内签署 |
| 工资单 | 每月发放 |
| 工时记录 | 打卡记录 |
| 社会保险 | 及时缴纳 |
| 安全生产 | 法定要求 |
| 平等就业 | 禁止歧视 |

### 违规处罚

| 违规 | 处罚 |
|------|------|
| 不签合同 | 罚款+赔偿 |
| 拖欠工资 | 罚款+利息 |
| 违规解雇 | 2倍赔偿 |
| 未缴社保 | 罚款+补缴 |

---

**劳动法结论**：卢旺达劳动法保障较为完善，核心是书面合同、最低工资$78/月、18天年假、解雇补偿。关键是本地化比例（70%+）和社保合规。
