## 申请流程

### RDB投资认证

```
Step 1: RDB接洽
  → 了解激励政策

Step 2: 提交申请
  → 商业计划书
  → 投资规模
  → 就业计划

Step 3: RDB审核
  → 激励资格认定

Step 4: 获得认证
  → 投资注册证书
  → 激励确认函

Step 5: RRA税务
  → 申请免税资格
  → 年度合规报告
```

### ITIDA额外申请

| 步骤 | 机构 | 时效 |
|------|------|------|
| ITIDA申请 | ICT Authority | 2-4周 |
| 业务审查 | RDB | 2周 |
| 最终批准 | ITIDA Board | 2周 |

## 合规要求

### 年度合规

| 要求 | 时效 | 机构 |
|------|------|------|
| 年度税务申报 | 每年3月31日 | RRA |
| 激励使用报告 | 每年 | RDB |
| 就业报告 | 每季度 | MIFOTRA |
| 社保缴纳 | 每月 | RSSB |
| 审计报告 | 每年 | 独立审计 |

### 激励撤销

| 情况 | 后果 |
|------|------|
| 未达投资承诺 | 补缴税款+罚款 |
| 违规操作 | 取消激励资格 |
| 虚假申报 | 补缴+罚款+刑事责任 |
| 重大变更 | 重新申请 |

---

**税收激励结论**：卢旺达激励体系完善，核心是RDB投资认证锁定激励。ITIDA认证（10年免税）和KSEZ入驻（前5年免税）是最大激励。关键是年度合规报告以维持激励资格。
