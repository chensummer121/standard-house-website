# 肯尼亚法律概览

## 法律体系

肯尼亚承袭英国普通法体系，独立后保留了殖民时期的法律框架，同时逐步完善本土立法。法律体系相对成熟，对外资较为友好，但执行层面存在效率问题和腐败风险。

## 宪法框架

**2010年宪法**
- 三权分立：行政、立法、司法
- 权力下放：中央+47个郡政府
- 基本权利保障
- 司法独立

**司法机构**
- 最高法院（上诉终审）
- 上诉法院
- 高等法院
- 各类专门法院（劳工法院、土地法院等）
- 治安法院

**法律传统**
- 英国普通法
- 成文法
- 先例原则

## 商业法律

### 公司法

**主要法规**
- 公司法（Companies Act, 2015）
- 替代投资市场（AIM）

**公司类型**
| 类型 | 说明 |
|------|------|
| 私人公司（Private Company） | 最常见，股东2-50人 |
| 上市公司（Public Company） | 可上市，股东无上限 |
| 外国公司（Foreign Company） | 外国公司在肯设立分支机构 |
| 分公司（Branches） | 外国公司分支机构 |

**注册要求**
- 公司名称（不重名）
- 注册地址（肯尼亚地址）
- 股东（至少1人）
- 董事（私人公司至少1人）
- 公司秘书（私人公司）

**注册机构**
- 肯尼亚公司注册局（Registrar of Companies）
- 注册时间：1-3个工作日（标准）
- 注册费：根据注册资本

### 合同法

**合同要素**
- 要约与承诺
- 对价（Consideration）
- 合法目的
- 当事人能力

**合同类型**
- 买卖合同
- 租赁合同
- 服务合同
- 劳动合同

**争议解决**
- 协商
- 调解
- 仲裁（推荐）
- 诉讼

### 知识产权

**主要法规**
- 知识产权法（Industrial Property Act, 2001）
- 版权法（Copyright Act）
- 商标法（Trade Marks Act）

**保护类型**
- 专利（Patent）：20年
- 商标（Trademark）：10年，可续期
- 版权（Copyright）：作者有生之年+50年
- 商业秘密：无限期

**注册机构**
- 肯尼亚知识产权局（KIPI）

## 土地法律

### 土地类型

| 类型 | 说明 |
|------|------|
| 政府土地 | 国有，可租赁99年 |
| 社区土地 | 部落/社区所有 |
| 私人土地 | 私有，可购买 |

**土地登记**
- 土地注册局（Registrar of Land）
- 土地登记证书（Title Deed）
- 交易需律师协助

### 土地交易

**购买流程**
1. 尽职调查（律师）
2. 签订买卖协议
3. 土地转让申请
4. 缴纳税费
5. 登记过户

**注意事项**
- 土地纠纷普遍
- 双重出售风险
- 社区土地问题

## 劳动法律

### 雇佣法规

**主要法规**
- 劳动法（Labour Relations Act）
- 就业法（Employment Act）
- 职业安全与健康法

**核心权利**
- 最低工资保障
- 工作时间限制
- 带薪假期
- 解雇保护
- 反歧视

**社保义务**
- NSSF（国家社保基金）：员工5%）
- NHIF（国家医疗保险基金）：员工收入1%）
- 退休金计划（PAYE）

## 税务法律

### 主要税种

| 税种 | 税率 | 说明 |
|------|------|------|
| 企业所得税 | 30% | 标准税率 |
| 个人所得税 | 10-35% | 累进税率 |
| VAT | 16% | 标准税率 |
| 预扣税 | 0-30% | 分类型 |
| 资本利得税 | 5% | 2022年新征 |

### 税收体系

**KRA（肯尼亚税务局）**
- 税收征管
- 纳税人登记（TIN）
- 税务审计

**合规要求**
- 年度申报
- 月度申报（增值税、预扣税）
- 税务审计应对

## 投资法律

### 投资准入

**鼓励领域**
- 出口导向型产业
- 高科技产业
- 制造业
- 农业加工
- 旅游业

**投资机构**
- KenInvest：一站式投资服务
- EPZ：出口加工区

### 外资限制

**原则上开放**
- 外国投资者可100%持股
- 利润可汇出（需合规）

**限制领域**
- 武器弹药
- 核能
- 赌博业
- 部分农业

## 争议解决

### 仲裁

**机构**
- 肯尼亚国际仲裁中心（KIAC）
- 伦敦国际仲裁院（LCIA）
- 国际商会（ICC）

**优势**
- 保密性
- 专业性
- 跨境执行（纽约公约）

### 诉讼

**程序**
- 一审：高等法院
- 二审：上诉法院
- 终审：最高法院

**问题**
- 速度慢（数年）
- 成本高
- 腐败风险

### 替代争议解决

- 调解（Mediation）
- 协商（Negotiation）
- 小额索赔法院

## 合规建议

### 1. 法律尽职调查

**必须调查**
- 交易对手资信
- 土地/资产权属
- 合同条款
- 知识产权
- 税务合规

### 2. 专业顾问

**必备顾问**
- 律师（商业、房产、劳动）
- 会计师
- 税务顾问

**推荐来源**
- 当地知名律所
- 国际律所肯尼亚办公室
- 中国驻肯使馆推荐

### 3. 合规体系

**建立机制**
- 合同管理
- 合规检查
- 争议预防
- 文件存档

## 一句话建议

> **肯尼亚法律体系相对完善，但"有法不依、执法不严"是常见问题。法律文件要做扎实，专业顾问不可少，合规成本要预算够。**
