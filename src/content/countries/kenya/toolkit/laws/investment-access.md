# 肯尼亚投资准入

## 外资政策框架

肯尼亚对外资总体友好，原则上允许100%外资持股，无需本地合资。但部分行业有外资限制，需特别注意。肯尼亚是《巴黎公约》和《纽约公约》成员国，知识产权保护相对完善。

## 外资准入规则

### 原则上开放

**可100%外资持股**
- 制造业（大部分）
- 服务业（大部分）
- 贸易/零售（大部分）
- 农业（部分）
- 科技/互联网

**无需本地合资**
- 除特定行业外
- 可独资经营
- 可设立子公司

### 外资限制行业

**绝对限制（仅肯尼亚公民）**
- 武器弹药制造
- 核能生产
- 赌博/彩票业
- 部分安全和军事服务

**需要许可**
- 渔业（深海捕捞需许可）
- 电信（网络运营商需许可）
- 航空（国内航空需许可）
- 保险（特定产品需许可）

**本土化要求**
- 土地购买：外国人仅能租赁（99年）
- 部分政府采购：本地优先

### 特定行业要求

**农业投资**
- 外国投资者可购买/租赁土地
- 农业用地开发需NEMA环评
- 部分农产品出口需许可

**制造业**
- 出口导向型企业可申请EPZ
- 制造业激励可申请

**能源**
- 发电需能源管理局许可
- PPA与KPLC签订
- 特定项目需内阁批准

**金融**
- 银行：CBK许可
- 保险：IRA许可
- 资本市场：CMA许可

## 公司设立

### 公司类型

**私人有限公司（Private Company）**
- 最常见形式
- 股东2-50人
- 不能公开募股
- 股东责任有限

**上市公司（Public Company）**
- 可在内罗毕证券交易所上市
- 股东无上限
- 需满足上市要求

**外国公司分支机构**
- 外国公司的延伸
- 需注册为"外国公司"
- 需本地注册代理人

**代表处**
- 只能做调研/联络
- 不得从事商业经营
- 注册要求简单

### 注册流程

1. **名称核准**
   - 向公司注册局申请
   - 名称不与已注册公司重名
   - 2-3个工作日

2. **提交文件**
   - 公司章程（Memorandum）
   - 公司章程细则（Articles）
   - 注册地址证明
   - 董事/股东身份证明
   - 公司秘书任命

3. **支付费用**
   - 注册费根据股本
   - 约$100-500

4. **领取证书**
   - 公司注册证书
   - 2-3个工作日

5. **后续登记**
   - 税务登记（TIN）
   - VAT登记（如需要）
   - 社保登记（NSSF、NHIF）
   - 劳动力合规

### 注册时间

- 标准注册：5-7个工作日
- 加急服务：1-2个工作日
- 通过律师代办：更便捷

## 投资激励政策

### 一般投资激励

**适用条件**
- 在肯尼亚投资
- 创造就业
- 技术转让（可选）
- 本地采购（可选）

**激励类型**
- 税收激励
- 土地优惠
- 简化流程
- 基础设施

### EPZ（出口加工区）

**适用条件**
- 85%以上产品出口
- 符合EPZ产品目录
- 获得EPZ管理局许可

**优惠**
- 企业所得税豁免（10年）
- 增值税豁免
- 关税豁免（进口材料）
- 预扣税豁免
- 无外汇管制
- 一站式服务

**申请流程**
1. 向EPZ管理局申请
2. 提交商业计划
3. 场地审核
4. 颁发许可证

### 优先行业激励

**农业**
- 农业投资激励
- 农产品加工激励
- 出口激励

**制造业**
- 制造业激励
- 区域激励
- 出口激励

**旅游业**
- 酒店投资激励
- 旅游设施激励

**能源**
- 可再生能源激励
- IPP政策支持

## 工作签证

### 签证类型

**投资签证**
- Class G（投资者）
- Class D（投资者代表）
- 需KenInvest推荐信

**工作签证**
- Class A（肯尼亚稀缺技能）
- Class B（公司雇员）
- 需雇主担保

**普通签证**
- Class C（普通居民）
- 基于家庭关系等

### 申请要求

**基本材料**
- 护照（6个月以上有效期）
- 照片
- 申请表格
- 费用支付

**投资签证额外**
- KenInvest推荐信
- 投资证明文件
- 公司注册文件

**工作签证额外**
- 雇主担保函
- 劳动合同
- 学历证明
- 劳动力市场测试（部分）

### 处理时间

- 标准：2-4周
- 加急：1周
- 投资签证：1-2周（KenInvest通道更快）

## 土地获取

### 外国投资者土地政策

**购买限制**
- 外国人不能购买土地
- 仅能租赁

**租赁选项**
- 99年租赁权（政府土地）
- 长期租赁（私人土地，通常50-99年）
- 租赁权可注册

### 土地获取途径

1. **政府土地**
   - 通过招标/申请
   - 99年租赁
   - EPZ园区土地

2. **私人土地**
   - 购买（通过本地实体）
   - 长期租赁（50-99年）
   - 合资开发

3. **园区土地**
   - EPZ园区
   - 工业园区
   - 科技园区

### 注意事项

- 土地纠纷普遍
- 尽职调查必须
- 聘请专业律师
- 避免购买争议土地

## 知识产权保护

### 保护类型

**商标**
- 注册机构：KIPI
- 有效期：10年，可续期
- 保护范围：商品/服务类别

**专利**
- 注册机构：KIPI
- 有效期：20年
- 要求：新颖性、创造性

**版权**
- 自动保护
- 注册可选
- 有效期：作者有生之年+50年

### 执法

- 警察/海关执法
- 法院诉讼
- 仲裁（KIPI）
