# 坦桑尼亚物流与清关体系

## 核心结论

物流效率低下是坦桑贸易的最大痛点——达市港口清关7-14天，远慢于蒙巴萨。专业清关服务是投资坦桑物流的最佳切入点。

---

## 一、物流体系

### 1.1 主要物流节点

| 节点 | 功能 | 特点 |
|------|------|------|
| 达累斯萨拉姆港 | 进出口核心 | 效率低、拥堵 |
| 姆特瓦拉港 | 辅助港口 | 设施老旧 |
| 机场 | 航空货运 | 规模小 |
| 边境 | 跨境贸易 | 手续复杂 |

### 1.2 物流成本

| 项目 | 成本 | 说明 |
|------|------|------|
| 港口费用 | $50-100/TEU | 装卸、仓储 |
| 清关费用 | $100-300/TEU | 代理、文件 |
| 运输成本 | $150-250/吨 | 达市-基戈马 |
| 总物流成本 | 占货值15-25% | 高于东非平均 |

---

## 二、清关体系

### 2.1 清关流程

| 步骤 | 时间 | 负责机构 |
|------|------|---------|
| 提交文件 | 1天 | 货代 |
| 海关审核 | 2-3天 | TRA |
| 检验检查 | 1-2天 | 海关 |
| 缴纳税费 | 1-2天 | TRA |
| 放行提货 | 1-2天 | TPA |
| **总计** | **7-14天** | - |

### 2.2 关税税率

| 商品类别 | 税率 |
|---------|------|
| 原材料/资本品 | 0% |
| 半成品 | 10% |
| 成品 | 25% |
| 敏感商品 | 35-100% |

## 四、结论

> **物流是坦桑贸易的最大痛点，也是最大机会。**清关服务是最佳切入点**——低成本、高回报、需求刚性。现在布局，等于在物流痛点上挖金矿。**
