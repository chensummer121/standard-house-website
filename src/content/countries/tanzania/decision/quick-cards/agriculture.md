# 快速决策卡：农业

## 一句话结论

> **坦桑尼亚是东非农业资源最丰富的国家之一，腰果产量全球领先，咖啡品质优异。但90%农产品以生料出口，加工环节极度匮乏——这就是你的机会。**

## 投资逻辑（3分钟理解）

### 为什么是农业？

1. **资源禀赋突出**：热带气候、充足土地、廉价劳动力，农业条件优越
2. **出口市场稳定**：腰果、咖啡、烟草都有稳定国际市场，本币成本换美元收入
3. **政策支持**：萨米娅政府鼓励农产品本地加工，取消出口禁令
4. **竞争不充分**：本地加工能力不足，外国投资者有机会主导

### 为什么是加工而非种植？

| 对比维度 | 种植 | 加工 |
|---------|------|------|
| 土地风险 | 极高（产权不稳） | 低（工厂用地） |
| 政策风险 | 高 | 低 |
| 资本密集度 | 高 | 中 |
| 回报率 | 10-15% | 20-40% |
| 外汇获取 | 难 | 易（出口创汇） |

## 详细赛道分析

### 🥇 腰果加工（最高优先级）

**投资逻辑**：
- 坦桑是世界最大腰果生产国之一（年产30万吨+）
- 印度、越南主导全球腰果加工，坦桑本土加工能力不足
- Suluhu已取消生腰果出口禁令，但本地加工仍是政策鼓励方向
- 腰果加工增值10倍以上：带壳$1,200/吨→去壳熟制$4,000-12,000/吨

**投资规模**：
- 加工厂建设：150-300万美元
- 加工设备（去壳机、烘干机）：50-100万美元
- 运营资金：50-100万美元（原材料采购）
- 预期回报：25-40% IRR

**关键成功因素**：
- 与产区合作社建立长期供货协议（锁定原料）
- 达累斯萨拉姆/姆特瓦拉港口物流便利
- 符合国际食品安全标准（FDA、EU认证）

### 🥈 咖啡烘焙出口

**投资逻辑**：
- 坦桑咖啡品质优异（水洗阿拉比卡），RCA指数高
- 90%出口生豆，附加值流失——每公斤生豆$3-5，品牌烘焙后$20-50
- 中国咖啡消费爆发，坦桑咖啡进入中国市场机会巨大
- 咖啡期货对冲风险，现货贸易+期货锁定利润

**投资规模**：
- 湿处理厂+烘干设备：80-150万美元
- 烘焙设备：30-50万美元
- 运营资金：50-100万美元
- 预期回报：20-35% IRR

**关键成功因素**：
- 锁定优质产区合作社（阿鲁沙、乞力马扎罗产区）
- 建立可追溯体系（区块链/二维码）
- 获取有机/雨林联盟认证

## 决策建议

| 你的情况 | 建议 |
|---------|------|
| 有农产品加工经验 | 强烈推荐腰果加工/咖啡烘焙 |
| 有食品出口渠道 | 优先考虑咖啡品牌化 |
| 有资本无经验 | 寻找本地合伙人联合进入 |
| 想快速回本 | 选择高周转加工（腰果去壳） |

---

**一句话总结**：坦桑农业是"资源禀赋+政策支持+市场需求"的三击机会。**腰果加工是最佳切入点**——原料充足、政策支持、外汇创收。现在入场，等于在别人还没反应过来时卡位。
