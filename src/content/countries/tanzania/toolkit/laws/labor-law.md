# 坦桑尼亚劳动法指南

## 核心结论

坦桑尼亚劳动法保护力度较强，解雇成本高，用工需谨慎。理解劳动法规是合规经营的基础。

---

## 一、劳动合同

### 1.1 合同类型

| 类型 | 期限 | 说明 |
|------|------|------|
| 固定期限合同 | ≤4年 | 可续期 |
| 无固定期限合同 | 无期限 | 默认类型 |
| 学徒合同 | 协商 | 培训用途 |
| 临时合同 | ≤6个月 | 临时工作 |

### 1.2 合同要求

- 必须书面签订
- 需包含：职位、工资、工作时间、地点
- 外语合同需翻译成斯瓦希里语

---

## 二、工资与工时

### 2.1 最低工资

| 行业 | 月薪(美元) |
|------|-----------|
| 农业 | 约$120 |
| 服务业 | 约$120 |
| 制造业 | 约$150 |
| 采矿业 | 约$180 |

### 2.2 工时规定

| 项目 | 规定 |
|------|------|
| 标准工时 | 每周45小时 |
| 加班工资 | 工作日150%，节假日200% |
| 年假 | 每工作12个月≥28天 |
| 病假 | 每年≤126天 |

---

## 三、解雇规定

### 3.1 解雇条件

| 类型 | 要求 |
|------|------|
| 试用期 | 1-6个月提前通知 |
| 违纪 | 严重违纪可立即解雇 |
| 经济性裁员 | 需支付补偿金 |
| 合同到期 | 支付服务金 |

### 3.2 解雇补偿

| 服务年限 | 补偿标准 |
|---------|----------|
| <6个月 | 无 |
| 6个月-1年 | 7天工资 |
| 1-5年 | 每满1年7天工资 |
| >5年 | 每满1年15天工资 |

---

## 四、社会保险

| 险种 | 雇主缴 | 员工缴 |
|------|-------|-------|
| 养老金(NSSF) | 10% | 10% |
| 医疗险(NHIF) | 固定额 | 固定额 |

---

## 五、外籍员工

| 要求 | 说明 |
|------|------|
| 工作许可 | 必须申请 |
| 配额限制 | 根据企业规模 |
| 学历要求 | 需专业资质 |

---

## 六、结论

> **坦桑劳动法对员工保护力度强，解雇成本高。建议：严格招聘流程、明确合同条款、避免违规解雇、建立良好的劳动关系。**
