# 坦桑尼亚外汇管制指南

## 核心结论

外汇管制是坦桑尼亚投资的"生死线"。TZS持续贬值、外汇储备波动、利润汇出需审批——理解外汇规则、提前规划资金安排，是投资成功的关键能力。

---

## 一、外汇管制框架

### 1.1 主管机构

| 机构 | 职责 |
|------|------|
| 坦桑尼亚央行（BOT） | 制定外汇政策、发放外汇许可 |
| 商业银行 | 执行外汇交易、代理央行审批 |
| 坦桑税务局（TRA） | 税务合规、预扣税征收 |

### 1.2 基本原则

- **经常项目**：相对自由，但需提供证明文件
- **资本项目**：需要央行批准
- **跨境支付**：通过授权商业银行办理

### 1.3 货币

| 项目 | 内容 |
|------|------|
| 本币 | 坦桑尼亚先令（TZS） |
| 官方汇率 | BOT每日公布 |
| 市场汇率 | 商业银行外汇市场 |
| 黑市 | 存在但价差不大 |

## 二、经常项目外汇规则

### 2.1 进口支付

| 条件 | 要求 |
|------|------|
| 基本要求 | 提供发票、提单（L/C或T/T） |
| 预付款 | ≤ USD 10,000无需证明 |
| 超过限额 | 需提供进口许可证（部分商品） |
| 支付方式 | L/C、T/T、D/P均可 |

### 2.2 出口收入

| 条件 | 要求 |
|------|------|
| 强制结汇 | 出口收入需汇回坦桑 |
| 结汇期限 | 180天内 |
| 豁免 | 大型资本设备进口可申请豁免 |
| 证明文件 | 出口发票、报关单 |

### 2.3 服务支付

| 支付类型 | 所需文件 | 预扣税 |
|---------|---------|--------|
| 咨询服务 | 合同、发票 | 10-15% |
| 技术服务 | 合同、发票 | 10-15% |
| 管理费 | 合同、董事会决议 | 10% |
| 运费 | 提单、发票 | 5% |
| 保险费 | 保单、发票 | 5% |

## 三、资本项目外汇规则

### 3.1 外国直接投资（FDI）

**投资汇入**：
- 无金额限制
- 需向银行提供：投资批准文件、公司注册文件
- 银行记录后，分配外汇登记号

**投资汇出**：
- 需央行批准
- 需提供：完税证明、外汇登记文件
- 审批时间：2-6周

### 3.2 利润汇出

| 条件 | 要求 |
|------|------|
| 基本要求 | 外汇登记、完税证明 |
| 外汇登记 | 需在BOT登记FDI |
| 完税证明 | 最近3年财务报表 |
| 审批时间 | 2-6周 |
| 预扣税 | 股息预扣10% |

**所需文件**：
1. 经审计财务报表（最近3年）
2. 完税证明
3. 董事会利润分配决议
4. 税务清关证明
5. 外汇登记证书

### 3.3 资本回收

| 类型 | 规则 |
|------|------|
| 股权转让 | 需央行批准，需提供完税证明 |
| 减资 | 需央行批准，需通知债权人 |
| 清算 | 需央行批准，需完成税务清算 |

### 3.4 贷款偿还

| 类型 | 规则 |
|------|------|
| 本金偿还 | 需央行批准 |
| 利息偿还 | 需提供贷款协议、偿付证明 |
| 预扣税 | 利息预扣10% |

## 五、实际操作指南

### 5.1 外汇账户开立

**所需文件**：
1. 公司注册证书
2. 公司章程
3. TIN（税号）
4. VAT证书
5. 董事会决议（开立外汇账户）
6. 实际受益人声明

**开立流程**：
1. 选择商业银行（CRDB、NMB、Stanbic等）
2. 提交上述文件
3. 银行审核（约1-2周）
4. 开立账户

### 5.2 利润汇出流程

| 步骤 | 内容 | 时间 |
|------|------|------|
| 1 | 召开董事会决定利润分配 | - |
| 2 | 完成税务清算，获取完税证明 | 2-4周 |
| 3 | 向银行提交申请 | 1-3天 |
| 4 | 银行初审 | 1-2周 |
| 5 | 银行向央行提交申请 | 1-2周 |
| 6 | 央行审批 | 2-6周 |
| 7 | 完成预扣税缴纳 | 1周 |
| 8 | 外汇汇出 | 1-3天 |
| **总计** | - | **6-12周** |

### 5.3 预扣税计算

**股息预扣税**：
```
预扣税 = 汇出股息 × 10%
示例：汇出$100万股息 → 预扣$10万 → 实汇$90万
```

**与服务费相关**：
```
预扣税 = 支付金额 × 10-15%
示例：支付$10万服务费 → 预扣$1-1.5万
```

|---------|------|------------|

| 支付类型 | 规则 |
|---------|------|
| 员工薪酬汇出 | 需完税证明、雇佣合同 |
| 遣散费汇出 | 需提供离职证明 |

### 6.3 紧急情况

**可申请加急处理的情况**：

- 其他紧急情况

**申请材料**：
- 紧急情况说明
- 相关证明文件
- 银行意见函

## 七、常见问题

### Q1: 利润汇出需要多久？
A: 正常情况6-12周，紧急情况可申请加急（2-4周）。

### Q2: 可以用美元定价合同吗？
A: 可以，且建议使用。美元合同可规避汇率风险。

### Q3: 可以持有美元现金吗？
A: 企业可持有一定限额美元用于业务经营，但需向银行申报。

### Q4: 如果央行拒绝批准怎么办？
A: 可向央行申诉，或通过外交途径（若涉及双边投资协定）。

### Q5: 有什么合法方式减少预扣税？
A: 利用中坦税收协定（若适用）、合理安排支付结构、选择最优支付类型。

## 八、合规建议

### 8.1 日常合规

1. **外汇登记**：FDI汇入后立即办理外汇登记
2. **记录保存**：保留所有外汇交易的完整记录
3. **税务合规**：确保税务申报及时、准确
4. **定期报告**：按要求向央行/银行提交外汇报告

### 8.2 资金规划

1. **提前规划**：利润汇出需提前6个月准备
2. **分散汇出**：避免大额一次性汇出
3. **时间选择**：关注汇率走势，选择有利时机
4. **多元路径**：准备多个汇出路径（正式+非正式）

### 8.3 风险控制

1. **汇率对冲**：使用远期合约锁定汇率
2. **自然对冲**：增加本币收入，减少外汇敞口
3. **保险覆盖**：考虑政治风险保险（覆盖汇兑限制）
4. **本地化**：提高本地采购比例，减少外汇需求

---

## 九、结论

> **外汇管制是坦桑投资的"必修课"。核心原则：**提前规划、合规先行**。利润汇出需要6-12个月准备时间；美元计价合同是规避汇率风险的最佳工具；政治风险保险可以覆盖最坏情况（全面外汇管制）。**
