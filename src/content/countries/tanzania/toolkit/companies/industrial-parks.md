# 坦桑尼亚工业园区指南

## 核心结论

坦桑尼亚政府将工业园区作为工业化的核心抓手，全国现有约15个工业园区（含EPZ/SEZ）。对于制造业投资者，选择正确的工业园区可以大幅降低投资成本、规避政策风险、加速业务落地。

---

## 一、园区体系概览

### 1.1 园区类型

| 类型 | 定义 | 数量 | 主要园区 |
|------|------|------|---------|
| **EPZ（出口加工区）** | 面向出口的制造企业 | 约10个 | Mwanza、Bagamoyo等 |
| **SEZ（经济特区）** | 综合型工业区 | 约5个 | Kenneth、Kigoma等 |
| **工业公园** | 政府规划工业区 | 若干 | 多地分布 |
| **私营园区** | 私人投资运营 | 少数 | 少量 |

### 1.2 园区地理分布

| 区域 | 主要园区 | 定位 |
|------|---------|------|
| 达累斯萨拉姆区 | Mwalimu Nyerere、Benjamin Mkapa | 制造业、服务业 |
| 阿鲁沙区 | Acacia | 农业加工、旅游配套 |
| 姆万扎区 | Mwanza EPZ | 矿业服务、制造业 |
| 乞给马区 | Kenneth SEZ | 综合制造 |
| 沿海区 | Bagamoyo | 港口物流、制造 |

## 二、主要工业园区详情

### 2.1 Mwalimu Nyerere工业园（达累斯萨拉姆）

**基本信息**：
- 位置：达累斯萨拉姆市郊
- 面积：约2,500公顷
- 成立：2006年
- 管理：坦桑尼亚工业园区管理局（TANIP）

**产业定位**：
- 制造业（纺织、服装、电子组装）
- 服务业
- 物流仓储

**优惠政策**：

| 优惠类型 | 内容 |
|---------|------|
| 土地 | 99年租约，价格$30-50/sqm |
| 税收 | 前5年免税，后续10年减半 |
| 进口 | 生产设备、原材料关税减免 |
| 电力 | 优先保障供应，价格补贴 |
| 服务 | 一站式审批服务 |

**基础设施**：
- 道路：铺设良好
- 电力：专用变电站
- 水：供水系统
- 通讯：光纤覆盖

**主要入驻企业**：
- 纺织服装类（约30家）
- 电子组装类（约10家）
- 食品加工类（约15家）

**招商门槛**：
- 最低投资额：$100万美元
- 最低就业：100人
- 环保要求：符合EIA标准

### 2.2 Benjamin Mkapa工业园（达累斯萨拉姆）

**基本信息**：
- 位置：达累斯萨拉姆
- 面积：约1,000公顷
- 定位：纺织、服装、农产品加工

**特色**：
- 与港口距离近（20公里）
- 劳动力密集型产业聚集
- 享受EPZ全部优惠政策

### 2.3 Acacia工业园（阿鲁沙）

**基本信息**：
- 位置：阿鲁沙市郊
- 面积：约500公顷
- 定位：农业加工、矿业服务、旅游配套

**优势**：
- 靠近乞力马扎罗国际机场
- 咖啡、腰果产区
- 旅游Safari基地

**适合产业**：
- 咖啡/剑麻加工
- 矿业服务
- Safari装备制造

### 2.4 Kenneth经济特区（乞给马）

**基本信息**：
- 位置：乞给马区
- 面积：约15,000公顷（东非最大SEZ之一）
- 定位：综合制造、矿业加工、物流

**规划产业**：
- 矿业冶炼加工
- 重型制造业
- 港口物流
- 能源产业

**政策支持**：
- 联邦政府直接支持
- 特殊税收激励
- 基础设施优先

**当前状态**：
- 开发进度较慢
- 多数地块未开发
- 投资需谨慎评估

### 2.5 Mwanza出口加工区

**基本信息**：
- 位置：姆万扎市郊
- 面积：约300公顷
- 定位：矿业服务、农产品加工

**优势**：
- 金矿带中心（Geita、North Mara矿）
- 维多利亚湖畔，水资源充足
- 劳动力成本低

**适合产业**：
- 矿业设备维修
- 黄金冶炼
- 渔产品加工

## 四、优惠政策详解

### 4.1 税收优惠

| 阶段 | 税率 | 条件 |
|------|------|------|
| 建设期 | 0% | 入园企业 |
| 前5年运营 | 0% | 出口加工企业 |
| 6-10年运营 | 10% | 出口加工企业 |
| 10年后 | 标准税率 | 25-30% |

### 4.2 进口优惠

| 商品 | 关税 | 增值税 |
|------|------|--------|
| 生产设备 | 0% | 0% |
| 原材料（出口用） | 0% | 0% |
| 成品内销 | 10-25% | 18% |

### 4.3 其他优惠

- **土地**：99年租约，可续期
- **工作许可**：外籍员工配额灵活
- **水电**：价格补贴
- **服务**：一站式审批（公司注册、许可、签证等）

## 五、选择园区指南

### 5.1 选择维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 位置 | 30% | 与市场、港口、原料的距离 |
| 基础设施 | 25% | 电力、水、道路、通讯 |
| 政策支持 | 20% | 税收、土地、许可 |
| 劳动力 | 15% | 可获得性、成本、技能 |
| 社区环境 | 10% | 安全、社区关系 |

### 5.2 产业匹配推荐

| 你的产业 | 推荐园区 | 理由 |
|---------|---------|------|
| 纺织服装 | Benjamin Mkapa | 产业聚集、劳动力密集 |
| 电子组装 | Mwalimu Nyerere | 基础设施好、靠近港口 |
| 农业加工 | Acacia、Mwanza | 原料产地、价格低 |
| 矿业服务 | Mwanza EPZ | 靠近金矿带 |
| 重型制造 | Kenneth SEZ | 土地价格低、面积大 |
| 物流仓储 | Bagamoyo | 靠近港口 |

### 5.3 决策建议

| 你的优先级 | 推荐园区 |
|------------|---------|
| 快速落地 | Mwalimu Nyerere、Benjamin Mkapa |
| 降低成本 | Acacia、Mwanza、Kenneth |
| 长期发展 | Kenneth SEZ（低价囤地） |
| 靠近港口 | Benjamin Mkapa、Bagamoyo |
| 靠近原料 | Acacia（咖啡）、Mwanza（金矿） |

## 六、入园流程

### 6.1 标准流程

| 步骤 | 时间 | 负责机构 |
|------|------|---------|
| 1. 意向申请 | - | 投资者 |
| 2. 项目评估 | 2-4周 | TANIP/EPZA |
| 3. 土地分配 | 4-8周 | 园区管理局 |
| 4. 环评批复 | 4-12周 | NEMC |
| 5. 注册许可 | 2-4周 | 多部门 |
| 6. 开工许可 | 2-4周 | 地方政府 |
| **总计** | **3-6个月** | - |

### 6.2 注意事项

1. **最低投资额**：通常要求$100万+
2. **就业承诺**：需承诺创造就业（通常100+）
3. **本地采购**：鼓励使用本地原材料
4. **环保合规**：必须通过环境影响评估（EIA）
5. **外汇安排**：需提前规划外汇管理

## 七、常见问题

### Q1: 园区土地是永久产权吗？
A: 不是，是99年租约。但可续期，实际等同于永久。

### Q2: 可以购买已有厂房吗？
A: 可以。部分园区有现成厂房出租或出售。

### Q3: 外籍员工比例有限制吗？
A: 有一定限制，但园区内相对宽松。需合理安排本地化比例。

### Q4: 园区内有金融服务吗？
A: 部分大型园区有银行网点。达累斯萨拉姆周边园区金融服务完善。

### Q5: 园区内企业可以内销吗？
A: 可以，但需缴纳相应关税和增值税。EPZ企业内销比例通常有限制。

## 八、结论

> **选择正确的工业园区是坦桑制造业投资成功的关键一步。达累斯萨拉姆周边园区（Mwalimu Nyerere、Benjamin Mkapa）基础设施好、配套全，适合快速落地；阿鲁沙、姆万扎园区成本低、靠近原料，适合农业加工和矿业服务；Kenneth SEZ面积大、价格低，但开发进度慢，适合长期布局。**

---

**建议**：
1. **先确定产业定位**，再选择匹配园区
2. **实地考察**是必须的，不要只看宣传材料
3. **了解园区当前状态**，有些园区承诺很好但实际进展慢
4. **计算全成本**：土地+基础设施+运营成本
5. **关注园区管理方**：政府园区vs私营园区服务质量差异大
