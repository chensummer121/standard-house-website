# 坦桑尼亚数据来源指南

## 核心结论

准确的数据是投资决策的基础。以下整理坦桑尼亚主要官方和第三方数据来源，供投资研究参考。

---

## 一、官方数据来源

### 1.1 政府机构

| 机构 | 网站 | 数据类型 |
|------|------|---------|
| 坦桑统计局（NBS）| nbs.go.tz | 人口、GDP、贸易 |
| 坦桑央行（BOT）| bot.go.tz | 金融、汇率、外汇 |
| 坦桑税务局（TRA）| tra.go.tz | 税收、贸易 |
| 矿业部 | mise.go.tz | 矿产数据 |
| 贸易部 | mit.go.tz | 贸易数据 |
