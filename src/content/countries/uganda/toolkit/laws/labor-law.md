# 劳工法规指南

## 一、监管框架

### 1.1 主要法规

| 法规 | 说明 |
|------|------|
| 《劳动法》(Employment Act) | 核心劳动法律 |
| 《工人赔偿法》(Workers Compensation Act) | 工伤赔偿 |
| 《工会法》(Trade Unions Act) | 工会组织 |
| 《国家社保法》(NSSF Act) | 社保制度 |

### 1.2 主管机构

| 机构 | 职责 |
|------|------|
| Ministry of Gender, Labour and Social Development | 政策制定 |
| Directorate of Labour | 执法监督 |
| National Social Security Fund (NSSF) | 社保管理 |

---

## 二、劳动合同

### 2.1 合同类型

| 类型 | 适用 | 说明 |
|------|------|------|
| 定期合同 | 特定期限 | 最长2年，可续约 |
| 不定期合同 | 无固定期限 | 长期雇用 |
| 学徒合同 | 培训目的 | 特定行业 |
| 临时合同 | 临时工作 | 最长6个月 |

### 2.2 必备条款

| 条款 | 说明 |
|------|------|
| 雇主/雇员信息 | 双方身份 |
| 职位描述 | 工作内容 |
| 工作地点 | 明确地点 |
| 工作时间 | 规定工时 |
| 薪酬 | 金额/支付周期 |
| 试用期 | 可选 |
| 解雇条款 | 终止条件 |

### 2.3 试用期

| 规定 | 说明 |
|------|------|
| 最长期限 | 6个月 |
| 提前通知 | 无需（可随时终止） |
| 续约 | 不可续约，只能转正式 |

---

## 三、工作时间

### 3.1 标准工时

| 类型 | 时数 | 备注 |
|------|------|------|
| 标准工作周 | 48小时 | 8小时/天×6天 |
| 或 | 40小时 | 8小时/天×5天 |
| 加班上限 | 每周48小时 | 需支付加班费 |

### 3.2 休息规定

| 休息类型 | 时间 |
|---------|------|
| 用餐休息 | 至少1小时/天 |
| 连续休息 | 每周至少24小时 |
| 年假 | 见下文 |

## 四、薪酬规定

### 4.1 最低工资

⚠️ **需深搜**：当前最低工资标准
- 乌干达目前**无全国统一最低工资法**
- 部分行业有最低工资标准
- 实践中工资由市场决定

### 4.2 加班费

| 类型 | 费率 |
|------|------|
| 普通加班 | 基本工资×1.5 |
| 夜间加班 | 基本工资×2.0 |
| 节假日加班 | 基本工资×2.0 |

### 4.3 工资支付

| 规定 | 说明 |
|------|------|
| 支付周期 | 月付（常见） |
| 支付方式 | 银行转账或现金 |
| 工资单 | 必须提供 |
| 货币 | UGX |

## 八、解雇与裁员

### 8.1 正当理由

| 类型 | 说明 |
|------|------|
| 试用期不合格 | 可终止 |
| 能力不足 | 需证明 |
| 行为不当 | 需严重程度 |
| 业务需要 | 经济性裁员 |

### 8.2 解雇程序

```
第一步：正当理由评估
    ↓
第二步：书面通知（或代通知金）
    ↓
第三步：提前通知/代通知金
    ↓
第四步：支付应得款项
        - 未休年假折算
        - 代通知金
        - 遣散费（如适用）
```

### 8.3 遣散费

| 服务年限 | 遣散费 |
|---------|-------|
| 1年以下 | 无 |
| 1-5年 | 7天/年 |
| 5-10年 | 15天/年 |
| 10年以上 | 20天/年 |

### 8.4 不当解雇

| 类型 | 后果 |
|------|------|
| 无故解雇 | 赔偿+复职 |
| 歧视解雇 | 严厉处罚 |
