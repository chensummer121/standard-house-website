# 外汇管制指南

## 一、监管框架

### 1.1 主要法规

| 法规 | 说明 |
|------|------|
| 《外汇法》(Foreign Exchange Act) | 核心法律 |
| Bank of Uganda指令 | 执行规定 |
| URA海关规定 | 进出口外汇管理 |

### 1.2 主管机构

| 机构 | 职责 |
|------|------|
| Bank of Uganda (BOU) | 外汇政策制定 |
| Uganda Revenue Authority (URA) | 进出口外汇执行 |
| 商业银行 | 外汇交易执行 |

---

## 二、经常项目自由化

### 2.1 贸易外汇

| 项目 | 管制程度 | 说明 |
|------|---------|------|
| 进口付汇 | **基本自由** | 需证明文件 |
| 出口收汇 | **基本自由** | 需申报 |
| 服务贸易付汇 | **基本自由** | 需证明文件 |
| 投资收益汇出 | **自由** | 需完税证明 |

### 2.2 所需文件（进口付汇）

| 文件 | 用途 |
|------|------|
| 商业发票 | 交易证明 |
| 提单/运单 | 货物证明 |
| 进口许可证（如需） | 合规证明 |
| TIN证明 | 身份证明 |

---

## 三、资本项目管理

### 3.1 FDI（外国直接投资）

| 项目 | 规定 |
|------|------|
| 流入 | 自由，需注册 |
| 登记 | 30天内向BOU报告 |
| 利润汇出 | 自由，需满足条件 |
| 资本汇出 | 受限，需批准 |

### 3.2 投资登记流程

```
第一步：外资进入时向BOU登记
    ↓
第二步：获得外资登记证明
    ↓
第三步：保留完整交易记录
    ↓
第四步：汇出时出示登记证明
```

## 四、利润与股息汇出

### 4.1 基本规则

| 条件 | 说明 |
|------|------|
| 完税证明 | 企业所得税已缴 |
| 审计报告 | 经审计财务报表 |
| 登记证明 | 外资登记证明 |
| 银行关系 | 需在乌干达银行有账户 |

### 4.2 所需文件

| 文件 | 说明 |
|------|------|
| 完税证明 | URA出具 |
| 审计报告 | 最近年度 |
| 董事会决议 | 利润分配决议 |
| 外资登记证明 | BOU出具 |
| 银行对账单 | 显示利润汇入 |

### 4.3 时间线

| 步骤 | 时间 |
|------|------|
| 准备文件 | 1-2周 |
| 银行审核 | 1-2周 |
| BOU审批 | 2-4周 |
| **总计** | **约1-2个月** |

## 五、个人外汇规定

### 5.1 个人汇款

| 类型 | 限额 | 说明 |
|------|------|------|
| 旅行外汇 | 合理数量 | 需证明用途 |
| 生活费用 | 无限制 | 需合法来源 |
| 赡养费 | 无限制 | 需证明关系 |

### 5.2 外籍员工薪酬

| 项目 | 规定 |
|------|------|
| 本币薪酬 | 必须在UGX账户发放 |
| 外币薪酬 | 部分允许，需批准 |
| 汇出 | 自由，需完税 |

## 七、汇率风险管理

### 7.1 汇率走势

| 货币对 | 趋势 | 说明 |
|--------|------|------|
| UGX/USD | 缓慢贬值 | 年均3-5% |
| UGX/EUR | 跟随欧元 | 波动 |
| UGX/CNY | ⚠️ 需深搜 | - |

### 7.2 避险工具

| 工具 | 可获得性 | 适用 |
|------|---------|------|
| 远期锁汇 | 有限 | 大额交易 |
| 自然对冲 | 推荐 | 美元收入企业 |
| 价格传导 | 可行 | 消费品 |
| 美元存款 | 普遍 | 持有美元 |

### 7.3 建议策略

**策略一：美元化运营**
- 开立美元账户
- 美元收入+美元支出
- 减少汇率风险

**策略二：成本本地化**
- 优先本地采购
- 减少外汇需求
- 提高本币比例

## 八、合规要求

### 8.1 报告义务

| 报告 | 频率 | 对象 |
|------|------|------|
| 外资登记 | 一次性 | BOU |
| 外汇交易 | 银行记录 | 银行 |
| 跨境支付 | 银行审核 | URA |

### 8.2 违规处罚

| 违规 | 处罚 |
|------|------|
| 无证外汇交易 | 罚款/没收 |
| 逃汇 | 刑事责任 |
| 虚假申报 | 罚款/起诉 |

### 8.3 合规建议

| 建议 | 说明 |
|------|------|
| 保持记录 | 完整交易文件 |
| 合规银行 | 选择合规良好的银行 |
| 专业顾问 | 必要时聘请 |
| 主动申报 | 避免被动核查 |
