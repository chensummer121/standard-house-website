# 土地获取指南

## 一、土地制度概览

### 1.1 宪法框架

| 条款 | 内容 |
|------|------|
| 宪法第237条 | 土地属于乌干达公民 |
| 宪法第26条 | 保护私有财产权 |
| 外国人限制 | 仅能Leasehold，不能直接拥有 |

### 1.2 土地权属类型

| 类型 | 所有者 | 说明 |
|------|--------|------|
| Freehold | 公民个人 | 最完整所有权 |
| Mailo | 公民个人/机构 | Buganda地区特有 |
| Leasehold | 公民/外国人 | 租赁，外国人唯一选择 |
| Customary | 社区/个人 | 传统习惯法持有 |

---

## 二、四种土地制度详解

### 2.1 Freehold（自由持有）

| 特征 | 说明 |
|------|------|
| 持有者 | 仅限乌干达公民 |
| 权利 | 最完整，可自由处分 |
| 期限 | 永久，无期限 |
| 登记 | 土地局登记 |

#### 权利与限制

| 权利 | 说明 |
|------|------|
| 使用开发 | 完全自由 |
| 转让 | 可出售给任何公民 |
| 出租 | 可出租，期限不限 |
| 抵押 | 可抵押贷款 |

### 2.2 Mailo（米洛持有）

| 特征 | 说明 |
|------|------|
| 历史来源 | 1900年《乌干达协议》 |
| 主要分布 | Buganda地区（中部乌干达） |
| 持有者 | 个人/机构，需是公民 |
| 双重权益 | 地主+租户（Kibanja）同时存在 |

#### 特殊复杂性

| 权益方 | 权利 |
|--------|------|
| Mailo地主 | 拥有土地，可收取租金 |
| 合法占用者(Legal Occupant) | 世代居住，不可驱逐 |
| Kibanja持有者 | 有作物/建筑权益，转让需通知地主 |

⚠️ **关键风险**：Mailo地主与Kibanja租户之间的权益冲突是土地纠纷的主要来源

### 2.3 Leasehold（租赁持有）

| 特征 | 说明 |
|------|------|
| 持有者 | 公民和**外国人均可** |
| 来源 | 政府或私人地主 |
| 期限 | 通常**49年或99年** |
| 续约 | 可续约 |

#### 外国人获取Leasehold

| 方式 | 说明 |
|------|------|
| 从政府租赁 | 通常是政府持有的公有土地 |
| 从Mailo地主租赁 | 需地主同意 |
| 从Freehold地主租赁 | 需地主同意 |

### 2.4 Customary（习惯持有）

| 特征 | 说明 |
|------|------|
| 持有者 | 社区/家族/个人 |
| 法律基础 | 传统习惯法 |
| 登记 | 可获得习惯所有权证书(CCO) |
| 转让 | 受习惯法限制 |

## 三、外资土地获取流程

### 3.1 外国人唯一选择：Leasehold

```
第一步：确定土地类型和权属
    ↓
第二步：尽职调查（产权调查）
    ↓
第三步：谈判并签署协议
    ↓
第四步：获得土地局批准（如适用）
    ↓
第五步：签署正式租赁协议
    ↓
第六步：土地局登记
```

### 3.2 Leasehold获取步骤

#### 第一步：确定土地权属

| 检查项 | 内容 |
|--------|------|
| 产权证书 | 核实真伪 |
| 权属历史 | 是否有纠纷 |
| 抵押情况 | 是否有贷款抵押 |
| 占用情况 | 是否有非法占用 |

#### 第二步：尽职调查

| 调查项 | 说明 |
|--------|------|
| 产权链 | 完整无争议 |
| 土地局记录 | 与实际一致 |
| 税务状况 | 无欠税 |
| 规划限制 | 用途限制 |
| 环境评估 | 环评要求 |

#### 第三步：谈判与协议

| 事项 | 建议 |
|------|------|
| 价格谈判 | 充分了解市场 |
| 租金/期限 | 49年优先99年 |
| 特殊条款 | 续约权等 |

#### 第四步：政府批准（如适用）

| 情况 | 要求 |
|------|------|
| 大型项目 | 土地委员会批准 |
| 农业用地 | 农业部长批准 |
| 超过额度 | ⚠️ 需深搜 |

#### 第五步：登记

| 步骤 | 说明 |
|------|------|
| 土地局提交 | Kampala Central Registry |
| 缴纳费用 | 登记费+印花税 |
| 等待登记 | 数周至数月 |

## 四、土地费用

### 4.1 购买/租赁成本

| 费用类型 | 估算 |
|---------|------|
| 土地价格 | 依位置差异巨大 |
| 登记费 | 成交价的1-2% |
| 律师费 | 成交价的1-3% |
| 印花税 | 依交易类型 |

### 4.2 Leasehold租金

| 类型 | 说明 |
|------|------|
| 政府土地 | 通常按评估价值一定比例 |
| 私人土地 | 双方协商 |

---

## 五、关键风险

### 5.1 主要风险

| 风险 | 描述 | 影响程度 |
|------|------|---------|
| 产权纠纷 | Mailo双重权益 | **高** |
| 非法占用 | 侵占土地 | **高** |
| 欺诈 | 假产权证 | **高** |
| 社区冲突 | 与当地社区 | 中 |
| 政府征用 | 公共利益征用 | 中 |
| 规划变更 | 土地用途改变 | 中 |

### 5.2 风险规避建议

| 建议 | 具体措施 |
|------|---------|
| 专业尽职调查 | 聘请律师+ surveyor |
| 产权保险 | 购买产权保险 |
| 本地合伙人 | 了解当地情况 |
| 长期租赁 | 优先选择有良好记录的 |
| 政府土地 | 风险较低 |

## 七、特殊考量

### 7.1 农业用地

| 考量 | 说明 |
|------|------|
| 农业用地限制 | ⚠️ 需深搜具体限制 |
| 土地用途变更 | 需批准 |
| 环评要求 | 大面积种植需评估 |

### 7.2 环境保护

| 要求 | 说明 |
|------|------|
| 湿地保护 | 不可占用湿地 |
| 森林保护 | 不可砍伐保护区 |
| 环评要求 | 大型开发需环评 |

### 7.3 社区关系

| 事项 | 建议 |
|------|------|
| 咨询当地 | 提前与社区沟通 |
| 补偿方案 | 合理补偿占用者 |
| 就业承诺 | 承诺就业机会 |
| 社会许可 | 获取社区支持 |

## 八、实操建议

### 8.1 流程时间线

| 阶段 | 时间 |
|------|------|
| 尽职调查 | 2-4周 |
| 谈判签署 | 2-4周 |
| 政府批准 | 4-8周 |
| 登记 | 4-12周 |
| **总计** | **3-6个月** |

### 8.2 专业团队

| 角色 | 职责 |
|------|------|
| 律师 | 法律尽职调查/协议 |
| 测量师 | 土地测量/边界确认 |
| 会计师 | 财务评估 |
| 评估师 | 土地估值 |
| 产权公司 | 产权保险 |

### 8.3 注意事项

| 注意事项 | 说明 |
|---------|------|
| 避免Mailo地 | 纠纷风险高 |
| 优先政府土地 | 产权清晰 |
| 工业园优先 | 减少风险 |
| 专业调查 | 不可省略 |
| 长期视角 | 土地使用权期限 |
