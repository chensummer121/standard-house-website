# 税务指南

## 一、税务概览

### 1.1 税务体系

| 税种 | 税率 | 征收机构 |
|------|------|---------|
| 企业所得税 | 30% | URA |
| 个人所得税 | 10-40% | URA |
| 增值税(VAT) | 18% | URA |
| 预提税(WHT) | 多档 | URA |
| 关税 | 0-25% | URA |
| 消费税 | 多档 | URA |
| 印花税 | 依交易 | URA |
| 地方税 | 依地方 | 地方政府 |

### 1.2 主管机构

| 机构 | 职责 |
|------|------|
| Uganda Revenue Authority (URA) | 税收征管 |
| Uganda Registration Services Bureau (URSB) | 印花税 |

---

## 二、企业所得税

### 2.1 基本税率

| 类型 | 税率 | 说明 |
|------|------|------|
| 标准税率 | **30%** | 适用于大多数公司 |
| 小微企业 | 20-30% | 收入分级 |

### 2.2 居民企业

- 税务居民定义：注册地或管理地在乌干达
- 征税范围：**全球收入**
- 非居民企业：仅对乌干达来源收入征税

### 2.3 应税所得计算

| 收入类型 | 计税方式 |
|---------|---------|
| 营业收入 | 全额计入 |
| 资本利得 | 单独计税 |
| 股息（国内） | 免税或部分计入 |
| 利息 | 全额计入 |
| 特许权使用费 | 全额计入 |

### 3.4 可扣除费用

| 费用类型 | 可扣性 |
|---------|-------|
| 业务相关支出 | ✅ 可扣 |
| 利息支出 | ✅ 可扣（有限制） |
| 招待费 | ⚠️ 有限额 |
| 罚款/滞纳金 | ❌ 不可扣 |
| 捐赠 | ⚠️ 有限额 |

---

## 三、增值税（VAT）

### 3.1 税率结构

| 税率 | 适用范围 |
|------|---------|
| **18%** | 标准税率，适用于大多数商品和服务 |
| 0% | 出口、本地出口商品、特定豁免 |
| 豁免 | 特定商品和服务 |

### 3.2 注册要求

| 门槛 | 金额 |
|------|------|
| 注册门槛 | **USh 1.5亿/年** | 
| 强制注册 | 超门槛必须注册 |
| 自愿注册 | 可选 |

### 3.3 主要豁免项目

| 豁免项目 | 说明 |
|---------|------|
| 初级农产品 | 未加工农产品 |
| 药品/医疗 | 基本医疗物资 |
| 教育 | 正式教育服务 |
| 金融服务 | 基本金融 |
| 土地/住宅 | 特定物业交易 |

### 3.4 零税率项目

| 零税率项目 | 说明 |
|-----------|------|
| 出口商品 | 实际出口 |
| 国际运输 | 跨境运输服务 |
| 特定进口 | ⚠️ 需确认 |

---

## 四、预提税（WHT）

### 4.1 股息预提税

| 类型 | 税率 | 备注 |
|------|------|------|
| 居民企业支付 | **15%** | 最终税 |
| 非居民企业 | **15%** | 可申请减免 |

### 4.2 利息预提税

| 类型 | 税率 |
|------|------|
| 本地利息 | 15% |
| 境外利息 | 20%（可减免） |

### 4.3 服务费/特许权使用费

| 类型 | 税率 |
|------|------|
| 本地付款 | 6-15% |
| 境外付款 | 15-20% |

### 4.4 租金预提税

| 类型 | 税率 |
|------|------|
| 个人租金 | 12% |
| 企业租金 | 无 |

---

## 五、关税

### 5.1 税率结构

| 税率 | 适用范围 |
|------|---------|
| 0% | 原材料、特定设备 |
| 10% | 半成品 |
| 15-25% | 制成品 |
| 特殊保护税 | 特定敏感商品 |

### 5.2 特殊关税

| 关税类型 | 说明 |
|---------|------|
| 消费税附加 | 特定进口商品 |
| 保障税 | 进口激增时 |
| 反倾销税 | ⚠️ 需深搜 |

## 十、实操要点

### 10.1 税务登记

| 步骤 | 说明 |
|------|------|
| TIN申请 | 基本，必需 |
| VAT注册 | 超门槛必注 |
| 消费税注册 | 销售特定商品 |

### 10.2 最佳实践

| 建议 | 说明 |
|------|------|
| 专业顾问 | 聘请当地税务顾问 |
| 税务规划 | 合法节税 |
| 记录保存 | 7年+ |
| 及时申报 | 避免罚款 |
| 对话沟通 | 与URA保持联系 |

### 10.3 常见风险

| 风险 | 影响 |
|------|------|
| 转让定价 | 关联交易需合规 |
| 常设机构 | 非居民需注意 |
| PE风险 | ⚠️ 需专业评估 |
