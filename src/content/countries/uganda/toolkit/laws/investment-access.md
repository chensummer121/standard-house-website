# 投资准入指南

## 一、监管框架

### 1.1 主要法规

| 法规 | 说明 |
|------|------|
| 《投资法》(Investment Code Act) | 核心投资法律 |
| 《公司法》(Companies Act) | 企业注册 |
| 《土地法》(Land Act) | 土地获取 |
| 《移民法》(Immigration Act) | 工作许可 |

### 1.2 主管机构

| 机构 | 职责 |
|------|------|
| Uganda Investment Authority (UIA) | 投资促进与注册 |
| Uganda Registration Services Bureau (URSB) | 企业注册 |
| Ministry of Trade, Industry and Cooperatives | 行业监管 |

---

## 二、投资注册流程

### 2.1 步骤概览

```
第一步：获取TIN（税号）→ URA
    ↓
第二步：注册公司 → URSB
    ↓
第三步：注册投资项目 → UIA
    ↓
第四步：获取投资许可证
    ↓
第五步：办理工作许可（如需）
```

### 2.2 公司注册（URSB）

| 类型 | 适用 | 备注 |
|------|------|------|
| 私人有限公司 | 多数情况 | 最常见 |
| 公众有限公司 | 上市公司 | 需更多要求 |
| 外国公司分支 | 外资企业 | 需额外文件 |

#### 注册要求

| 要求 | 说明 |
|------|------|
| 公司名称 | 预先核准 |
| 注册地址 | 乌干达本地地址 |
| 董事 | 至少1人 |
| 股东 | 至少1人 |
| 注册资本 | 无最低要求（实践中建议） |
| 注册时间 | 3-7个工作日 |

### 2.3 投资注册（UIA）

#### 强制注册门槛

| 投资类型 | 最低投资额 |
|----------|-----------|
| 本土投资者 | USh 5000万（约$13.5万） |
| 外资投资者 | **USh 25亿（约$68万）** |
| 特定行业 | 可能另有要求 |

#### 注册流程

| 步骤 | 时间 |
|------|------|
| 提交申请 | 当日 |
| 初审 | 3-5个工作日 |
| 批准 | 5-10个工作日 |
| 颁发证书 | 1-2个工作日 |

## 三、行业限制

### 3.1 禁止行业（外资）

⚠️ **需深搜**：完整禁止清单，通常包括：
- 武器制造
- 毒品生产
- 军事设施

### 3.2 限制行业

| 行业 | 限制内容 | 备注 |
|------|---------|------|
| 银行业 | 需央行批准 | 外资可参与 |
| 保险业 | 需监管批准 | 开放 |
| 矿业 | 需特别许可 | 对外开放 |
| 航空 | 需特别许可 | 限制 |

### 3.3 优先行业

| 行业 | 激励 |
|------|------|
| 制造业 | 出口导向优先 |
| 农业加工 | 投资优惠 |
| 基础设施建设 | 政策支持 |
| 信息技术 | 发展鼓励 |

---

## 四、最低投资额

### 4.1 外资要求

| 投资类型 | 最低金额 | 备注 |
|----------|---------|------|
| 一般外资 | USh 25亿 | ~$68万 |
| 工业园内投资 | 可能豁免 | 依项目 |
| 重大投资 | 个案评估 | - |

### 4.2 本土投资

| 投资类型 | 最低金额 |
|----------|---------|
| 本土投资者 | USh 5000万 |

## 五、签证与工作许可

### 5.1 签证类型

| 类型 | 适用 | 停留时间 |
|------|------|---------|
| 旅游签证 | 短期访问 | 90天 |
| 商务签证 | 商务活动 | 可延期 |
| 投资签证 | 投资者 | 可申请 |
| 工作许可 | 长期工作 | 必需 |

### 5.2 工作许可（Class A-G）

| 类别 | 适用 |
|------|------|
| Class A | 农业/畜牧业 |
| Class B | 制造业 |
| Class C | 贸易/服务 |
| Class D | 专业服务 |
| Class E | 采矿/石油 |
| Class F | 建筑业 |
| Class G | 政府指定 |

#### 申请要求

| 要求 | 说明 |
|------|------|
| 有效劳动合同 | 雇主出具 |
| 技能证明 | 资质证书 |
| 无犯罪记录 | 本国+乌干达 |
| 配额证明 | 雇主需证明本地人无法胜任 |

### 5.3 外国员工配额

- **通常要求**：企业需证明无法招募到合格的本地员工
- **管理人员**：通常允许更多外籍
- **技术岗位**：个案评估

## 六、实操要点

### 6.1 时间线（参考）

| 步骤 | 时间 |
|------|------|
| TIN申请 | 1-3天 |
| 公司注册 | 3-7天 |
| 投资注册 | 2-4周 |
| 银行开户 | 1-2周 |
| 工作许可 | 4-8周 |
| **总计** | **约2-3个月** |

### 6.2 费用参考

| 项目 | 费用 | 备注 |
|------|------|------|
| 公司注册 | ~USh 15万 | 政府费 |
| 投资注册 | ~USh 50万 | 政府费 |
| 工作许可 | ~USh 100-500万 | 依类别 |
| 律师/顾问 | $1000-5000 | 如需 |

### 6.3 注意事项

| 注意事项 | 说明 |
|---------|------|
| 本地合伙人 | 非强制，但建议 |
| 银行账户 | 建议尽早开设 |
| 银行关系 | 维护良好关系 |
| 合规记录 | 保持完整 |
| 本地顾问 | 建议聘请 |
