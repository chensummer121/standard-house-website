## 三、交通基础设施

### 3.1 标准轨铁路(SGR)

#### 项目概况

| 指标 | 详情 |
|------|------|
| 路线 | 坎帕拉-马拉巴(肯尼亚边境) |
| 长度 | 272公里 |
| 总投资 | **$31.9亿(€27亿)** |
| 设计时速 | 120 km/h |
| 预计工期 | 48个月 |

#### 进展历程

| 时间 | 事件 |
|------|------|
| 2015年 | 签约中国港湾(CHEC) |
| 2023年1月 | 终止中国合同(融资未落实) |
| 2024年10月 | 签约土耳其Yapi Merkezi |
| 2026年4月 | 花旗银行牵头融资 |
| 当前 | 融资谈判+前期工程 |

#### 融资结构

| 来源 | 比例 |
|------|------|
| 国际银团 | 85% |
| 政府 | 15% |
| UKEF | 待定 |

⚠️ **注**：融资尚未最终关闭
