# 坎帕拉：投资与生活指南

## 一、城市概览

### 基本信息

| 指标 | 数值 | 年份 | 可信度 |
|------|------|------|--------|
| 城市人口 | **187.5万** | 2024 | ★★★★☆ |
| 都会区人口 | **400-500万** | 2024 | ★★★☆☆ |
| 面积 | 189 km² | - | ★★★★☆ |
| 人口密度 | 9,125人/km² | 2024 | ★★★★☆ |
| 年增长率 | ~5% | 都会区 | ★★★★☆ |
| GDP占比 | ~50%+ | 2015 | ★★★☆☆ |

### 城市特征

| 特征 | 描述 |
|------|------|
| 别称 | 东非明珠 |
| 地形 | 建在多个山丘上 |
| 湖泊 | 维多利亚湖畔 |
| 商业中心 | 东非主要商业枢纽 |

**核心定位**：坎帕拉是乌干达的政治、经济、文化中心，也是东非最重要的商业城市之一。
