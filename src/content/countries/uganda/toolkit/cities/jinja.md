# 金贾：投资与生活指南

## 一、城市概览

### 基本信息

| 指标 | 数值 | 年份 | 可信度 |
|------|------|------|--------|
| 城市人口 | **29.2万** | 2024 | ★★★★☆ |
| 区域 | 东部地区Busoga | - | ★★★★☆ |
| 距坎帕拉 | ~87km(东) | - | ★★★★☆ |
| 海拔 | 1,204米 | - | ★★★★☆ |
| 定位 | 工业城/尼罗河源头/旅游 | - | ★★★★☆ |

### 城市特征

| 特征 | 描述 |
|------|------|
| 尼罗河源头 | 世界最长河流起点 |
| 工业历史 | 乌干达早期工业化城市 |
| 旅游目的地 | 漂流/探险 |
| 农业腹地 | 糖/茶叶/玉米 |

**核心定位**：金贾是乌干达重要的工业城市和旅游目的地，尼罗河源头使其具有独特战略地位。
