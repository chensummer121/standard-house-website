## 八，数据使用建议

### 8.1 数据优先级

| 优先级 | 来源 | 可靠性 |
|--------|------|--------|
| 1 | UBOS/BOU/URA | 最高 |
| 2 | World Bank/IMF | 高 |
| 3 | 行业机构 | 中高 |
| 4 | 商业数据库 | 中 |
| 5 | 新闻媒体 | 中低 |

### 8.2 交叉验证

| 方法 | 说明 |
|------|------|
| 多源对比 | 同一数据多来源验证 |
| 时间序列 | 检查趋势一致性 |
| 逻辑检验 | 数据间逻辑关系 |
