# 油气：产业纵深分析

## 一、行业定位

### 生命周期阶段
**开发冲刺期**——Tilenga和Kingfisher项目接近商业生产，首油目标2025年

### 项目重要性

| 指标 | 数值 | 年份 | 可信度 |
|------|------|------|--------|
| Tilenga项目产能 | 4万桶/日 | 满产后 | ★★★★☆ |
| Kingfisher项目产能 | 4万桶/日 | 满产后 | ★★★★☆ |
| 总产能 | **8万桶/日** | 满产后 | ★★★★☆ |
| 首油目标 | **2025年** | Tilenga | ★★★★☆ |
| 总投资 | $100亿+ | 两项目合计 | ★★★★☆ |

### 主要参与者

| 公司 | 项目 | 股权 | 备注 |
|------|------|------|------|
| TotalEnergies (法国) | Tilenga | 主导 | 运营商 |
| CNOOC (中国) | Tilenga | 少数权益 | 参股 |
| CNOOC (中国) | Kingfisher | 主导 | 运营商 |
| UNOC (乌干达) | 两项目 | 政府权益 | 国家石油公司 |
| 乌干达政府 | 两项目 | 15-20% | 权益油 |

**核心结论**：乌干达石油开发进入最后冲刺阶段，2025年首油将改变国家经济格局，但石油收入分配机制存在争议。

## 二、重大项目详情

### 2.1 Tilenga项目

| 指标 | 数值 |
|------|------|
| 位置 | 阿尔伯特湖畔，尼尔湖盆地 |
| 运营商 | TotalEnergies |
| 股权结构 | TotalEnergies 56.65%, CNOOC 26.75%, UNOC 15% |
| 产能 | 4万桶/日（高峰期） |
| 钻井数 | 60+口油井 |
| 投资额 | ~$60亿 |
| 状态 | 建设中，接近完工 |
| 首油目标 | **2025年** |

#### Tilenga开发亮点
- **干式天然气回注**：避免天然气放空燃烧
- **环境标准**：严格遵循国际环保要求
- **本地化**：大量使用本地承包商和服务
