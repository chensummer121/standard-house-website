# 埃塞俄比亚重点项目追踪

## 一、能源领域

### 复兴大坝（Grand Ethiopian Renaissance Dam, GERD）

| 项目 | 详情 |
|-----|------|
| 类型 | 水力发电 |
| 位置 | 青尼罗河（紧邻苏丹边境） |
| 装机容量 | 5,150兆瓦（非洲最大） |
| 发电机组 | 13台×375兆瓦 |
| 总投资 | 约50亿美元 |
| 中方参与 | 中国水利水电、中国电建（机电设备） |
| 当前状态 | 已开始发电（2022年起） |
| 完全运营 | ⚠️ 需深搜最新进度 |

**里程碑**：
- 2011年：开工
- 2020年：开始蓄水
- 2022年：第一台机组发电
- 2023-2024年：多台机组陆续投产

**意义**：
```
🌊 非洲最大水电站
🌊 预计发电量占埃塞当前需求2-3倍
🌊 潜在向苏丹、肯尼亚、埃及出口电力
🌊 减少对化石燃料依赖
```

**争议**：
⚠️ 与埃及、苏丹的水权争议持续
⚠️ 三方谈判仍在进行

## 二、交通基础设施

### 亚吉铁路（Addis Ababa-Djibouti Railway）

| 项目 | 详情 |
|-----|------|
| 类型 | 电气化铁路 |
| 线路 | 亚的斯亚贝巴 ↔ 吉布提港 |
| 全长 | 约756公里 |
| 投资额 | 约40亿美元 |
| 中方融资 | 中国进出口银行 |
| 承建方 | 中国铁建、中国土木 |
| 设计时速 | 120公里/小时（货运） |
| 当前状态 | 运营中 |

**里程碑**：
- 2016年：开始试运营
- 2018年：正式商业运营
- 2023年：⚠️ 需深搜运能提升情况

**数据**：
```
📊 货运能力：1,200万吨/年
📊 客运：开通旅客列车
📊 运输时间：从2-3天缩短至12小时
```
