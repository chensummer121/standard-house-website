# 埃塞俄比亚税务指南

## 一、税收体系概览

### 税种一览表

| 税种 | 税率 | 征收对象 | 备注 |
|-----|------|---------|------|
| 企业所得税 | 30% | 企业利润 | 标准税率 |
| 增值税(VAT) | 15% | 商品和服务 | 标准税率 |
| 关税 | 0-35% | 进口商品 | 平均约17% |
| 附加税 | 10% | 进口商品 | CIF+关税后 |
| 物品税 | 5-500% | 特定商品 | 按类别 |
| 资本利得税 | 15% | 房产转让 | 商业用途 |
| 印花税 | 0.5-2% | 特定文件 | 按类型 |
| 个人所得税 | 0-35% | 个人收入 | 累进税率 |

## 二、企业所得税

### 标准税率
```
标准企业所得税率：30%
适用于：所有在埃塞俄比亚注册的企业
（包括外资企业和本地企业）
```

### 小型企业优惠
| 年营业额 | 税率优惠 |
|---------|---------|
| 50万比尔以下 | 20% |
| 50万比尔以上 | 30%（标准） |

### 亏损处理
- 亏损可向后结转5年
- 不可向前期追溯抵扣
- 仅可抵扣同类资本收益

### 可扣除费用
- 经营相关的必要支出
- 资产折旧
- 资产处置亏损（存货除外）
- 销售商品成本

### 预提税

| 类型 | 居民 | 非居民 |
|-----|------|-------|
| 股息 | 10% | 10% |
| 利息 | 5% | 10% |
| 特许权使用费 | 5% | 5% |
| 管理费 | 2% | 15%/10%（矿业） |

### 双重征税协定
```
埃塞俄比亚已签署12个税收协定：
英国、美国、中国、日本、德国、法国、
意大利、印度、荷兰、罗马尼亚、以色列、南非
```

## 三、增值税(VAT)

### 税率结构

| 类别 | 税率 | 适用范围 |
|-----|------|---------|
| 标准税率 | 15% | 大部分商品和服务 |
| 零税率 | 0% | 出口货物和服务 |
| 免税 | - | 部分基本生活品、药品 |

### 注册要求
```
年营业额达到50万比尔（约2万人民币）须进行VAT登记
```

### 可抵扣项目
- 进口或本地采购的进项税
- 须持有有效增值税发票
- 仅限用于应税供应

### 不动产相关

| 交易类型 | 税率 |
|---------|-----|
| 住宅租金 | 不征VAT |
| 商业租金 | 征VAT |
| 房产销售 | 不征VAT |

## 四、关税制度

### 关税税率

| 类别 | 税率范围 |
|-----|---------|
| 最低税率 | 0% |
| 最高税率 | 35% |
| 平均税率 | 约17% |
| 汽车类 | 可高达100%+ |

### 关税计算基础
```
计税价格 = CIF价格（货值+运费+保险）
```

### 关税免除（投资激励）

符合条件可免税进口：
- ✅ 资本设备/机械装置
- ✅ 建筑材料
- ✅ 工业园区资本财（100%上限）
- ✅ 运营所需替换零件（上限15%）
- ✅ 生产出口商品所需原材料
- ✅ 投资项目的运营车辆

### 附加税（Surtax）
```
税率：10%
计税基础：CIF + 关税 + 物品税 + VAT
```

## 五、物品税（Excise Tax）

### 税率范围
```
5% - 500%
（根据商品类别）
```

### 适用商品
- 烟草制品
- 酒精饮料
- 软饮料
- 糖类
- 食盐
- 化妆品/香水
- 乘用汽车
- 旧机动车（500%）

### 2024年新规
```
- 要求在应税商品上贴印花
- 引入唯一识别码（UI）追踪系统
- 适用于：酒精饮料、软饮料、烟草制品
```

## 六、免税期政策

### 工业园区优惠

| 园区 | 优惠内容 |
|-----|---------|
| 博莱莱米工业园 | 出口企业特殊优惠 |
| 哈瓦萨工业园 | 税收减免 |
| 其他指定园区 | 关税、所得税优惠 |

### 免税期适用条件
- 出口导向型企业
- 在指定工业园区内运营
- 符合特定行业要求（纺织、服装、皮革等）

### 免税期时长
```
依投资规模和类型确定，通常为3-5年
```

## 七、个人所得税（参考）

### 税率结构（2024）

| 月收入（比尔） | 税率 |
|--------------|------|
| 0 - 600 | 0% |
| 601 - 1,650 | 10% |
| 1,651 - 3,200 | 15% |
| 3,201 - 5,250 | 20% |
| 5,251 - 7,800 | 25% |
| 7,801 - 10,900 | 30% |
| 10,900以上 | 35% |

### 雇主社保缴纳
```
雇主须缴纳员工基本工资的11%作为社保
```

## 八、社保与养老金

> **法律依据**：第1268/2022号《私营组织雇员养老金公告》（Private Organization Employees' Pension Proclamation No. 1268/2022），2022年3月18日正式生效

| 类型 | 雇主缴纳 | 员工缴纳 | 基数 |
|-----|---------|---------|------|
| 社保基金 | **11%** | **7%** | 雇员月度基础工资 |
| 养老金 | 按规定 | 按规定 | |

> **关键合规**：雇主必须在每月从员工薪资中扣减相关款项之日起的**30天内**，将雇主+雇员部分汇总汇入专属养老金基金账户
>
> **外籍员工排除**：无埃塞俄比亚血统的外籍公民被明确禁止向该社保基金缴纳费用，且不享有任何相关待遇

### 铁腕执法机制
如果一家企业**连续三个月**未能按时足额缴纳养老金，社会保障机构有权直接通知任何商业银行从该企业账户中强行划扣，境内所有银行必须无条件配合。

## 九、税务申报

### 申报周期
```
企业所得税：季度预缴 + 年度申报（9月底截止）
增值税：月度申报
个人所得税：月度代扣代缴
```

### 支付频率
```
每年税务支付次数：约29次
（撒哈拉以南非洲平均：36.6次）
```

### 税务合规成本
```
占利润比例：约37.7%
（全球平均较高，但低于撒哈拉非洲平均48.6%）
```
