## 五、历史文化

### 殖民遗产
```
🏛️ 法国殖民建筑群
🏛️ 德雷达瓦火车站（法式建筑风格）
🏛️ 独特的城市肌理：沙漠绿洲与殖民建筑的结合
```

### 历史背景
| 时期 | 要点 |
|-----|------|
| 1902年 | 因亚的斯亚贝巴-吉布提铁路而建城 |
| 1936-1941年 | 意大利占领时期 |
| 1993年 | 成为特许城市（脱离索马里自治区） |

## 七、风险评估

### 政治安全
```
⚠️ 族群关系：奥罗莫族、索马里族、阿姆哈拉族共居，需关注族群关系
⚠️ 边境安全：靠近索马里边境，需注意安全动态
```

### 基础设施风险
```
⚠️ 气候条件：位于沙漠边缘，夏季高温
⚠️ 水资源：相对干燥，需解决工业用水
```

### 政策风险
```
⚠️ 外汇管制：埃塞俄比亚外汇管理制度
⚠️ 政策变动：投资政策可能有调整
```
