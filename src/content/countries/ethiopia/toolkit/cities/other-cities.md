# 埃塞俄比亚其他城市档案

## 一、德雷达瓦（Dire Dawa）

### 基本信息
| 项目 | 数据 |
|-----|------|
| 地位 | 亚的斯亚贝巴以外最大城市、第二大经济体 |
| 位置 | 东部（距亚的斯约450公里） |
| 人口 | 约50-60万 |
| 类型 | 联邦直辖市 |
| 海拔 | 约1,200米 |
| 气候 | 炎热干燥（热带沙漠边缘） |

### 经济特点
| 项目 | 说明 |
|-----|------|
| 经济支柱 | 贸易、物流、工业 |
| 区位优势 | 亚吉铁路重要节点 |
| 港口连接 | 近吉布提港 |
| 工业园区 | 德雷达瓦工业园 |

### 投资机遇
```
💼 物流与仓储（港口转运）
💼 贸易服务
💼 制造业（工业园区）
💼 农产品加工（周边农业）
💼 能源（太阳能潜力）
```

### 基础设施
```
✅ 亚吉铁路经过
✅ 公路连接
⚠️ 气候炎热，电力需求大
⚠️ 水资源相对紧张
```

## 四、迪雷达瓦（Djibouti/吉布提）说明

> 注：迪雷达瓦通常指Dire Dawa，已在上文说明。此处补充埃塞俄比亚东部另一重要城市。

### 吉布提（Djibouti City）

> **重要提示**：吉布提是独立国家，非埃塞俄比亚城市，但作为埃塞出海门户具有重要意义。

### 基本信息
| 项目 | 数据 |
|-----|------|
| 地位 | 吉布提共和国首都 |
| 人口 | 约100万 |
| 类型 | 独立国家首都 |
| 功能 | 埃塞俄比亚主要出海通道 |

### 经济特点
| 项目 | 说明 |
|-----|------|
| 经济支柱 | 港口服务、自由区 |
| 港口 | 东非主要转运港 |
| 自由区 | 吉布提国际自由区 |
| 战略价值 | 埃塞90%以上贸易通道 |

### 与埃塞合作
```
🤝 两国深度合作
🤝 亚吉铁路终点
🤝 埃塞设有自由区办事处
🤝 投资可考虑两国联动
```
