## 三、经济发展

### 经济概况
```
📊 主要产业：旅游业、制造业、教育、农业
📊 GDP贡献：阿姆哈拉州主要经济中心
📊 经济特点：服务业+制造业双驱动
```

### 产业结构
| 产业 | 比重 | 说明 |
|-----|------|------|
| 服务业 | 高 | 零售、政府服务、旅游配套 |
| 制造业 | 中 | 纺织、食品加工、农产品加工 |
| 农业 | 中低 | 塔纳湖周边灌溉农业 |
| 旅游业 | 高 | 主要收入来源之一 |

### 主要企业/工业园
| 名称 | 行业 | 备注 |
|-----|------|------|
| 巴哈达尔工业园 | 纺织服装、农产品加工 | 75公顷，2020年建成运营 |
| Nirvana Processing | 食品/有机农产品加工 | 印度企业，投资500万美元 |
| Paron Trading | 农产品加工 | 与IPDC签约入驻 |

## 四、基础设施

### 交通
| 项目 | 现状 |
|-----|------|
| 航空 | 巴哈达尔机场（每日约10班飞往亚的斯亚贝巴） |

| 城市交通 | 自行车、嘟嘟车、共享出租车 |

## 七、风险评估

### 安全风险
```
⚠️ 阿姆哈拉冲突（2023-2024）：地区曾发生武装冲突，可能影响商业运营
⚠️ 政治稳定性：需关注地区治理动态
```

### 基础设施风险
```
⚠️ 交通瓶颈：通往亚的斯亚贝巴仅有一条主路
⚠️ 季节性：雨季可能影响部分路段通行
```

```
⚠️ 外汇管制：⚠️ 待验证
```
