# 刚果金安全风险评估

## 风险总评

安全风险等级：**极高（9/10）**

刚果金东部持续冲突构成最高安全风险。M23叛军、卢旺达干预和多方武装团体使东部省份极度危险。

## 主要安全威胁

### 1. M23叛军
- **活动区域**：北基伍省、南基伍省
- **2023-2024**：占领戈马等城市
- **能力**：重型武器、战术协调

### 2. 其他武装团体
- **民主同盟军（ADF）**：活跃于贝尼地区
- **Mai Mai民兵**：多个地方武装组织
- **前M23**：部分重新武装

### 3. 卢旺达干预
- **证据**：联合国专家组确认卢旺达军事支持
- **规模**：数千卢旺达士兵参与
- **影响**：冲突持续升级

### 4. 人道危机
- **流离失所**：超600万人
- **死亡人数**：数千平民
- **性暴力**：普遍存在

## 安全建议

### 绝对必要
1. **东部省份禁止前往**：北基伍、南基伍、伊图里
2. **金沙萨和卢本巴希相对安全**
3. **专业安保公司**
4. **医疗撤离机制**

### 区域选择
| 区域 | 安全等级 | 建议 |
|------|----------|------|
| 东部省份 | 极高 | 禁止前往 |
| 金沙萨 | 中等 | 可有限运营 |
| 卢本巴希 | 低-中等 | 优先考虑 |
| 加丹加其他 | 低 | 可考虑 |
| 其他 | 变化 | 评估后决定 |

### 运营要求
1. 充分的安保预算
2. 本地安全顾问
3. 应急响应预案
4. 人员安全培训
