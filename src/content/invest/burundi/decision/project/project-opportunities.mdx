# 布隆迪项目机会

## 高优先级项目

### 1. Musongati镍矿开发
**项目描述**：开发世界第六大镍矿
**储量**：2.61亿吨，品位1.62%
**投资需求**：约10亿美元+
**模式**：PPP + 国际投资

**关键要求**：
- 铁路配套设施
- 电力供应
- 大规模投资

### 2. 咖啡产业链升级
**项目描述**：现代化咖啡加工和出口
**投资规模**：1000-5000万美元
**模式**：私营 + 政府支持

**机会**：
- 咖啡加工厂
- 质量认证
- 出口市场开发

### 3. 小型水电站
**项目描述**：利用水利资源发电
**投资规模**：500-2000万美元
**模式**：PPP或私营

**机会**：
- 清洁能源
- 碳信用
- 电网建设

## 中优先级项目

### 4. 稀土开发
**项目描述**：稀土开采和初步加工
**当前状态**：南非公司运营
**机会**：技术服务、加工设施

### 5. 农业加工
**项目描述**：农产品增值加工
**投资规模**：500-2000万美元
**机会**：
- 茶叶加工
- 园艺出口
- 食品加工

### 6. 道路基础设施
**项目描述**：主要道路修复和建设
**资金来源**：世界银行、非洲开发银行
**机会**：承包商、服务提供商

## 投资要求

### 通用要求
- 美元结算安排
- 可靠的外汇渠道
- 长期投资视野
- 风险承受能力

### 特定要求
| 项目类型 | 投资规模 | 技术要求 | 合作需求 |
|----------|----------|----------|----------|
| 矿业 | 1亿美元+ | 高 | 政府+国际 |
| 农业加工 | 500万-5000万 | 中 | 本地伙伴 |
| 基础设施 | 1000万+ | 高 | PPP |
| 能源 | 500万-5000万 | 高 | 政府合作 |

## 项目筛选标准

### 推荐标准
- [ ] 轻资产优先
- [ ] 美元结算
- [ ] 短周期回报
- [ ] 风险可控
- [ ] 有担保

### 避免项目
- 大量当地货币敞口
- 长期资产投资（无保护）
- 无政府支持的私人项目
- 高度监管行业
