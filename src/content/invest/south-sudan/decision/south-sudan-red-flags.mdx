# 南苏丹投资红线

## 绝对红线（绝对不能碰）

### 1. 政治敏感行业
[机密]
- 石油资产直接收购
- 政府合同（特别是安全相关）
- 选举相关业务

### 2. 土地直接购买
- 不要直接购买土地
- 土地纠纷可能导致暴力冲突
- 建议租赁或合作方式

### 3. 现金大额交易
- 超过$1,000现金交易应避免
- 银行转账优先
- 保留完整记录

### 4. 无担保商业安排
- 口头协议无效
- 无书面合同不做大额交易
- 避免无第三方担保的借贷

## 合规红线

### 反腐红线
- 不向任何政府官员行贿
- 不通过第三方隐藏行贿
- 不参与"加速费"安排
- 建立内部举报机制

### 劳动法红线
- 不雇用童工
- 不低于当地工资标准
- 按时支付工资
- 提供安全的工作环境

### 环境红线
- 不破坏当地水源
- 不进行非法采伐
- 不涉及野生动物制品
- 符合环保标准

## 风险监控指标

### 红线触发指标

| 指标 | 警戒线 | 行动 |
|------|--------|------|
| 安全评级 | 升至4级 | 启动撤离预案 |
| 汇率波动 | 单日>10% | 全面评估 |
| 石油产量 | 下降>30% | 减少投资 |
| 援助撤出 | 主要援助国 | 评估退出 |

### 预警指标

[机密]
1. 部落冲突加剧
2. 选举相关暴力
3. 政府军部署变化
4. 国际制裁风声

## 撤退策略

### 撤退触发条件
[机密]
1. 安全评级升至最高
2. 资产被扣押威胁
3. 主要合伙人被制裁
4. 持续无法运营

### 撤退程序
[机密]
1. 资产快速变现
2. 人员安全撤离
3. 关键文件转移
4. 法律程序保留
5. 保险索赔启动
